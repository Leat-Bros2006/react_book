React.js 01. Introduction to React.js

01. Introduction to React.js

1. Definition (តើវាជាអ្វី?):

React.js គឺជា JavaScript Library មួយដែលត្រូវបានអភិវឌ្ឍដោយ Meta (Facebook) សម្រាប់បង្កើត User Interface (UI) លើ Web Application ជាពិសេសគឺ Single Page Applications (SPA)[cite: 6]។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ធ្វើឱ្យការរៀបចំ UI មានភាពងាយស្រួល និងរហ័សតាមរយៈ Component-Based Architecture[cite: 6]។
  • បង្កើនល្បឿន Render និង Performance ដោយប្រើប្រាស់ Virtual DOM[cite: 6]។
  • អាច Re-use កូដ UI ឡើងវិញបាន ជួយកាត់បន្ថយការសរសេរកូដដដែលៗ[cite: 6]។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើប្រាស់នៅពេលបង្កើត Web App ដែលមានភាពស្មុគស្មាញ មាន Dynamic Data ច្រើន និងត្រូវការភាពរហ័សរហួនដូចជា Dashboard, Social Media, E-commerce ឬ SaaS Applications[cite: 6]។

4. Syntax (ទម្រង់កូដ React ដំបូង):

import React from 'react';

function App() {
  return (
    <div style={{ padding: '20px', background: '#E0F2FE' }}>
      <h1 style={{ color: '#0284C7' }}>សួស្តី React.js!</h1>
      <p>សូមស្វាគមន៍មកកាន់ការសិក្សា React.js ពីមូលដ្ឋាន!</p>
    </div>
  );
}

export default App;

5. Explanation (ការពន្យល់កូដ):

  • function App() គឺជា Functional Component ដែលប្រគល់មកវិញនូវធាតុ UI[cite: 6]។
  • style={{ ... }} ប្រើសម្រាប់កំណត់ Style ផ្ទាល់ក្នុង JSX ដោយមិនពឹងផ្អែកលើ Tailwind[cite: 2]។
  • export default App; នៅខាងក្រោមដាច់ដោយឡែក គឺដើម្បីឱ្យ File ផ្សេងទៀតអាច Import ទៅប្រើបាន[cite: 6]។

6. Output (លទ្ធផល):

បង្ហាញប្រអប់ពណ៌ខៀវខ្ចីដែលមានចំណងជើង "សួស្តី React.js!" និងអត្ថបទស្វាគមន៍នៅលើ Web Browser[cite: 6]។

7. Summary (សង្ខេបមេរៀន)៖ React គឺជា UI Library ផ្អែកលើ Components និង Virtual DOM ដែលជួយឱ្យគេហទំព័រដំណើរការលឿន ងាយស្រួលថែទាំ និងបង្កើត Single Page Applications (SPA) បានយ៉ាងមានប្រសិទ្ធភាព។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 4
React.js 02. React Development Environment

02. React Development Environment (Vite Setup)

1. Definition (តើវាជាអ្វី?):

React Development Environment គឺជាការរៀបចំកម្មវិធីជំនួយនានា (Node.js, npm និង Vite Build Tool) នៅលើម៉ាស៊ីនកុំព្យូទ័រ ដើម្បីបង្កើត និងដំណើរការ Project React យ៉ាងរលូន។

2. Purpose (ហេតុអ្វីត្រូវប្រើ Vite?):

  • ផ្តល់នូវល្បឿន Server ចាប់ផ្តើមលឿនជាង Create React App រាប់សិបដង។
  • គាំទ្រ Hot Module Replacement (HMR) កែប្រែកូដភ្លាម បង្ហាញលទ្ធផលភ្លាមៗដោយមិនបាច់ Reload ទំព័រ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅរាល់ពេលចាប់ផ្តើមបង្កើតគម្រោងកម្មវិធី React ថ្មីនៅលើម៉ាស៊ីនផ្ទាល់ខ្លួន។

4. Syntax (ពាក្យបញ្ជាបង្កើត Project ក្នុង Terminal):

# 1. បង្កើត Project React ថ្មីជាមួយ Vite
npm create vite@latest my-react-app -- --template react

# 2. ចូលទៅកាន់ Folder និងដំឡើង Packages
cd my-react-app
npm install

# 3. ដំណើរការ Server សាកល្បង
npm run dev

5. Explanation (ការពន្យល់កូដ):

  • npm create vite@latest ទាញយកគ្រោងឆ្អឹងកូដ React ស្តង់ដារចុងក្រោយបង្អស់។
  • npm install បង្កើត Folder node_modules ដែលផ្ទុកបណ្ណាល័យ React ទាំងអស់។
  • npm run dev បើក Server នៅលើអាសយដ្ឋាន http://localhost:5173។

6. Output (លទ្ធផល):

ផ្ទាំង Terminal នឹងបង្ហាញ Link http://localhost:5173/ ដែលអាចបើកមើលលើ Browser បាន។

7. Summary (សង្ខេបមេរៀន)៖ ការរៀបចំ Environment ដោយប្រើ Vite និង Node.js គឺជាគ្រឹះដំបូងបង្អស់សម្រាប់ដំណើរការ React Project ទំនើបប្រកបដោយល្បឿនលឿន និងប្រសិទ្ធភាពខ្ពស់។

React.js 03. JSX Fundamentals

03. JSX Fundamentals

1. Definition (តើវាជាអ្វី?):

JSX (JavaScript XML) គឺជា Syntax Extension របស់ JavaScript ដែលអនុញ្ញាតឱ្យយើងសរសេរ HTML ក្រឡោតក្នុង JavaScript បានយ៉ាងងាយស្រួល[cite: 2]។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ធ្វើឱ្យការបង្កើត UI មានភាពងាយស្រួលមើល ដូចការសរសេរកូដ HTML ធម្មតា។
  • អាចបង្កប់តម្លៃអថេរ (Variables) ឬគណនាក្នុងសញ្ញាខ្នងក្រពើ { }[cite: 2]។

3. When to Use (ច្បាប់សំខាន់ៗនៃ JSX):

  • Single Root: ត្រូវតែមាន Parent Element តែមួយគត់រុំពីក្រៅ (ឬប្រើ Fragment <>...</>)[cite: 2]។
  • Close All Tags: ស្លាកទាំងអស់ត្រូវតែបិទជានិច្ច ដូចជា <img />, <input />[cite: 2]។
  • Attributes: ប្រើ className ជំនួស class និង htmlFor ជំនួស for[cite: 2]។

4. Syntax (ទម្រង់កូដ JSX):

function CourseInfo() {
  const title = "React.js ពីមូលដ្ឋានដល់ការអនុវត្ត";
  const price = 45;

  return (
    <>
      <h2>វគ្គសិក្សា៖ {title}</h2>
      <p>តម្លៃ៖ ${price} (ចុះសល់ ${price - 10})</p>
      <input type="text" placeholder="បញ្ចូលឈ្មោះ..." />
    </>
  );
}

export default CourseInfo;

5. Explanation (ការពន្យល់កូដ):

  • <> ... </> (Fragment) រុំព័ទ្ធធាតុកូនដោយមិនបង្កើត <div> លើសក្នុង DOM[cite: 2]។
  • {title} និង {price - 10} បង្កប់ការគណនា JavaScript ក្នុង JSX[cite: 2]។
  • បញ្ចប់ដោយ export default CourseInfo; នៅខាងក្រោមដាច់ដោយឡែក។

6. Output (លទ្ធផល):

បង្ហាញចំណងជើងវគ្គសិក្សា អត្ថបទគណនាតម្លៃ និងប្រអប់ Input ដែលត្រូវបានបិទស្លាកត្រឹមត្រូវ[cite: 2]។

7. Summary (សង្ខេបមេរៀន)៖ JSX រួមបញ្ចូលគ្នារវាង HTML និង JavaScript ដោយតម្រូវឱ្យបិទស្លាកកូដទាំងអស់[cite: 2] មាន Root Element តែមួយ[cite: 2] និងប្រើប្រាស់ { } សម្រាប់បញ្ចេញតម្លៃអថេរ[cite: 2]។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 6
React.js 04. Array & Object Destructuring

04. Array & Object Destructuring (ES6+)

1. Definition (តើវាជាអ្វី?):

Destructuring គឺជា Syntax ក្នុង ES6+ សម្រាប់ទាញយកតម្លៃចេញពី Array (តាមលំដាប់លំដោយ Index) ឬចេញពី Object (តាមឈ្មោះ Property Key) មកដាក់ក្នុង Variables ដាច់ដោយឡែកយ៉ាងរហ័ស។

2. Purpose (ហេតុអ្វីត្រូវប្រើក្នុង React?):

  • Array Destructuring: ប្រើសម្រាប់បង្កើត State តាមរយៈ const [state, setState] = useState()។
  • Object Destructuring: ប្រើសម្រាប់ទាញយក Props ឬ Data ដោយមិនបាច់សរសេរ props.name ដដែលៗ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើរាល់ពេលហៅ Hooks និងពេលទទួល Props ក្នុងក្បាលអនុគមន៍ Component។

4. Syntax (ទម្រង់កូដ Destructuring):

// 1. Array Destructuring
const fruits = ["ចេក", "ស្វាយ", "ក្រូច"];
const [first, second] = fruits; // first = "ចេក", second = "ស្វាយ"

// 2. Object Destructuring ក្នុង Component
const teacher = { fullName: "លាត ប្រុស", skill: "React.js" };

function Profile() {
  const { fullName, skill } = teacher;
  return (
    <p>លោកគ្រូ {fullName} បង្រៀនមុខវិជ្ជា {skill}</p>
  );
}

export default Profile;

5. Explanation (ការពន្យល់កូដ):

  • const [first, second] ចាប់យកធាតុតាមលំដាប់ទីតាំង 0 និង 1 នៃ Array។
  • const { fullName, skill } ចាប់យកតម្លៃតាមឈ្មោះ Key នៃ Object ដោយផ្ទាល់។

6. Output (លទ្ធផល):

បង្ហាញអត្ថបទ៖ "លោកគ្រូ លាត ប្រុស បង្រៀនមុខវិជ្ជា React.js"។

7. Summary (សង្ខេបមេរៀន)៖ Destructuring ជួយសម្រួលការទាញយកទិន្នន័យពី Array និង Object ឱ្យខ្លីស្អាត ហើយជាមូលដ្ឋានគ្រឹះមិនអាចខ្វះបានក្នុង React (Props & useState)។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 7
React.js 05. React Components

05. React Components (Export & Import)

1. Definition (តើវាជាអ្វី?):

React Component គឺជាអនុគមន៍ JavaScript ឯករាជ្យ (ឈ្មោះផ្តើមដោយអក្សរធំ PascalCase) ដែលប្រគល់មកវិញនូវ JSX ហើយអាចភ្ជាប់គ្នារវាង File ផ្សេងៗតាមរយៈ Export និង Import។

2. Purpose (ភាពខុសគ្នារវាង Default Export និង Named Export):

  • Default Export: ប្រើ export default Name (ក្នុង 1 File មានបានតែ 1) ពេល Import មិនបាច់ដាក់សញ្ញា { } ឡើយ។
  • Named Export: ប្រើ export function Name (មានបានច្រើនក្នុង 1 File) ពេល Import ត្រូវដាក់ក្នុង { Name }។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលបំបែក UI ឱ្យទៅជាឯកសារតូចៗដូចជា Navbar.jsx, Button.jsx, និង Footer.jsx។

4. Syntax (ទម្រង់ Export និង Import):

// ឯកសារទី ១៖ src/components/Buttons.jsx
export function DangerBtn() {

React.js 06. Props

06. Props (Component Communication)

1. Definition (តើវាជាអ្វី?):

Props (Properties) គឺជាយន្តការសម្រាប់បញ្ជូនទិន្នន័យពី Component មេ (Parent) ចុះទៅកាន់ Component កូន (Child)។ Props គឺជាទិន្នន័យប្រភេទ Read-Only (កូនមិនអាចកែប្រែតម្លៃ Props បានទេ)។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ធ្វើឱ្យ Component តែមួយអាចយកទៅប្រើឡើងវិញបានច្រើនដងដោយបង្ហាញទិន្នន័យខុសៗគ្នា។
  • អាចបញ្ជូនបានទាំង String, Number, Boolean, Array, Object ឬ Function។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលដែលយើងមានកាត ឬប៊ូតុងដូចៗគ្នា តែត្រូវការចំណងជើង និងតម្លៃខុសៗគ្នា។

4. Syntax (ការទទួល Props តាមរយៈ Destructuring):

// Child Component
function UserCard({ name, role, isOnline }) {
  return (
    <div style={{ border: '1px solid #ccc', padding: '10px', marginBottom: '8px' }}>
      <h3>{name}</h3>
      <p>តួនាទី៖ {role} | ស្ថានភាព៖ {isOnline ? "Online" : "Offline"}</p>
    </div>
  );
}

// Parent Component
function App() {
  return (
    <div>
      <UserCard name="លាត ប្រុស" role="Instructor" isOnline={true} />
      <UserCard name="សុខា" role="Student" isOnline={false} />
    </div>
  );
}

export default App;

5. Explanation (ការពន្យល់កូដ):

  • { name, role, isOnline } បំបែក Props Object ផ្ទាល់ក្នុង Argument របស់អនុគមន៍។
  • តម្លៃជា Boolean ឬ Number ត្រូវដាក់ក្នុងសញ្ញា { } ដូចជា isOnline={true}។

6. Output (លទ្ធផល):

បង្ហាញប្រអប់ព័ត៌មានចំនួន 2 ដែលមានឈ្មោះ និងស្ថានភាពខុសគ្នា។

7. Summary (សង្ខេបមេរៀន)៖ Props គឺជាមធ្យោបាយបញ្ជូនទិន្នន័យពីលើចុះក្រោម (Parent to Child) ដោយមានលក្ខណៈ Read-Only ជួយឱ្យ Component មានភាពបត់បែន និងប្រើឡើងវិញបាន។

React.js 07. State and useState

07. State and useState Hook

1. Definition (តើវាជាអ្វី?):

State គឺជាអង្គចងចាំផ្ទៃក្នុងរបស់ Component សម្រាប់ផ្ទុកទិន្នន័យដែលអាចផ្លាស់ប្តូរបាន។ នៅពេល State ប្តូរតម្លៃ React នឹងធ្វើការ Re-render UI ឡើងវិញដោយស្វ័យប្រវត្តិតាមរយៈ useState។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • អថេរធម្មតា let x = 0 ពេលប្តូរតម្លៃ មិនធ្វើឱ្យ UI ផ្លាស់ប្តូរតាមឡើយ។
  • useState ផ្តល់នូវអថេរតម្លៃ និងអនុគមន៍ Setter ដើម្បីធ្វើបច្ចុប្បន្នភាព UI ភ្លាមៗ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់រាប់ចំនួនទំនិញ (Counter), បិទ/បើកផ្ទាំង Modal និងការរក្សាទុកទិន្នន័យ Form។

4. Syntax (ទម្រង់កូដ useState Counter):

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div style={{ padding: '10px' }}>
      <h3>ចំនួនចុច៖ {count}</h3>
      <button onClick={() => setCount(count + 1)}>បន្ថែម</button>
      <button onClick={() => setCount(0)}>កំណត់ឡើងវិញ</button>
    </div>
  );
}

export default Counter;

5. Explanation (ការពន្យល់កូដ):

  • const [count, setCount] = useState(0) ប្រើ Array Destructuring បង្កើត State តម្លៃ 0។
  • setCount(count + 1) បង្កើនតម្លៃ State និងបញ្ជាឱ្យ Re-render អេក្រង់។

6. Output (លទ្ធផល):

បង្ហាញលេខរាប់ដែលកើនឡើងរាល់ពេលចុចប៊ូតុង "បន្ថែម" និងត្រឡប់ទៅ 0 ពេលចុច "កំណត់ឡើងវិញ"។

7. Summary (សង្ខេបមេរៀន)៖ State គ្រប់គ្រងទិន្នន័យមានចលនា (Dynamic Data) ក្នុង Component។ ការផ្លាស់ប្តូរ State តាមរយៈ Setter Function នឹងធ្វើបច្ចុប្បន្នភាព UI ដោយស្វ័យប្រវត្តិ។

React.js 08. Event Handling

08. Event Handling (ការគ្រប់គ្រងព្រឹត្តិការណ៍)

1. Definition (តើវាជាអ្វី?):

Event Handling គឺជាការសរសេរអនុគមន៍ដើម្បីឆ្លើយតបទៅនឹងសកម្មភាពរបស់អ្នកប្រើប្រាស់នៅលើ UI ដូចជា onClick, onChange, onSubmit ដោយប្រើ camelCase។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ធ្វើឱ្យគេហទំព័រមានអន្តរកម្មឆ្លើយតប (Interactivity) ពេលអ្នកប្រើប្រាស់ចុច ឬវាយអត្ថបទ។
  • ចាប់យកតម្លៃពី Input តាមរយៈ Event Object (e.target.value)។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅលើគ្រប់ប៊ូតុង ប្រអប់វាយអក្សរ និងទម្រង់ Form ទាំងអស់។

4. Syntax (ទម្រង់កូដ onChange និង onClick):

import { useState } from 'react';

function InputBox() {
  const [text, setText] = useState("");

  return (
    <div>
      <input type="text" onChange={(e) => setText(e.target.value)} />
      <button onClick={() => alert(text)}>បង្ហាញសារ</button>
    </div>
  );
}

export default InputBox;

5. Explanation (ការពន្យល់កូដ):

  • e.target.value ចាប់យកអក្សរដែលកំពុងវាយក្នុង Input បញ្ជូនទៅក្នុង State text។
  • onClick={() => alert(text)} បង្ហាញផ្ទាំង Alert នូវអត្ថបទដែលបានវាយពេលចុចប៊ូតុង។

6. Output (លទ្ធផល):

ពេលវាយអក្សរក្នុងប្រអប់ ហើយចុចប៊ូតុង "បង្ហាញសារ" វានឹងលោតប្រអប់ Alert បង្ហាញអក្សរនោះ។

7. Summary (សង្ខេបមេរៀន)៖ Events ក្នុង React សរសេរជា camelCase និងបញ្ជូនជា Function Callback សម្រាប់ភ្ជាប់សកម្មភាពអ្នកប្រើប្រាស់ទៅនឹងការកែប្រែទិន្នន័យ។

React.js 09. Conditional Rendering

09. Conditional Rendering (ការបង្ហាញតាមលក្ខខណ្ឌ)

1. Definition (តើវាជាអ្វី?):

Conditional Rendering គឺជាការសម្រេចចិត្តបង្ហាញ ឬលាក់ធាតុ UI ណាមួយដោយផ្អែកលើលក្ខខណ្ឌពិត (true) ឬមិនពិត (false) នៃ State ឬ Props។

2. Purpose (វិធីសាស្ត្រពេញនិយមទាំង 2):

  • Ternary Operator (condition ? A : B): ប្រើពេលមានជម្រើស ២ ផ្ទុយគ្នា (ដូចជា Login / Logout)។
  • Logical AND (condition && A): ប្រើពេលចង់បង្ហាញធាតុ A លុះត្រាតែលក្ខខណ្ឌពិត។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់បង្ហាញសញ្ញា "Loading...", ការត្រួតពិនិត្យសិទ្ធិអ្នកប្រើប្រាស់ និងការបង្ហាញផ្ទាំងជូនដំណឹង។

4. Syntax (ទម្រង់កូដ Conditional Rendering):

function AuthButton({ isLoggedIn }) {
  return (
    <div>
      {isLoggedIn ? (
        <button>ចាកចេញ (Logout)</button>
      ) : (
        <button>ចូលគណនី (Login)</button>
      )}
    </div>
  );
}

export default AuthButton;

5. Explanation (ការពន្យល់កូដ):

  • បើ isLoggedIn ស្មើ true វានឹងបង្ហាញប៊ូតុង "Logout" តែបើ false វានឹងបង្ហាញប៊ូតុង "Login"។

6. Output (លទ្ធផល):

បង្ហាញប៊ូតុងត្រឹមត្រូវទៅតាមស្ថានភាពពិតនៃ Prop isLoggedIn។

7. Summary (សង្ខេបមេរៀន)៖ Conditional Rendering ប្រើប្រាស់ JavaScript Operators ដូចជា Ternary (? :) និង Logical AND (&&) ដើម្បីគ្រប់គ្រងការបង្ហាញ UI តាមស្ថានភាពជាក់ស្តែង។

React.js 10. Lists and Keys

10. Lists and Keys (ការបង្ហាញបញ្ជីទិន្នន័យ)

1. Definition (តើវាជាអ្វី?):

Lists Rendering គឺជាការបម្លែងបណ្តុំទិន្នន័យក្នុង Array ឱ្យទៅជាបញ្ជីនៃធាតុ JSX ដោយប្រើប្រាស់អនុគមន៍ Array.map() អមដោយការផ្តល់ Attribute key តែមួយគត់។

2. Purpose (ហេតុអ្វីត្រូវមាន Key?):

  • key ជួយឱ្យ React ដឹងច្បាស់ថាធាតុណាខ្លះត្រូវបានកែប្រែ បន្ថែម ឬលុបចេញពី DOM។
  • ជៀសវាងបញ្ហា Render ខុសប្រក្រតីនៅពេលធាតុក្នុងបញ្ជីមានការផ្លាស់ប្តូរទីតាំង។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើរាល់ពេលបង្ហាញទិន្នន័យជាបញ្ជី ដូចជាបញ្ជីមុខវិជ្ជា បញ្ជីផលិតផល ឬតារាងទិន្នន័យ។

4. Syntax (ទម្រង់កូដ map និង key):

const students = [
  { id: 101, name: "សុខា" },
  { id: 102, name: "ដារ៉ា" }
];

function StudentList() {
  return (
    <ul>
      {students.map(({ id, name }) => (
        <li key={id}>{name}</li>
      ))}
    </ul>
  );
}

export default StudentList;

5. Explanation (ការពន្យល់កូដ):

  • students.map(...) បំប្លែង Object សិស្សម្នាក់ៗទៅជាស្លាក <li>។
  • key={id} ផ្តល់លេខ ID សម្គាល់ដាច់ដោយឡែកទៅឱ្យស្លាក <li> នីមួយៗ។

6. Output (លទ្ធផល):

បង្ហាញបញ្ជីឈ្មោះសិស្ស "សុខា" និង "ដារ៉ា" ជាចំណុចៗនៅលើទំព័រ។

7. Summary (សង្ខេបមេរៀន)៖ ការបង្ហាញទិន្នន័យច្រើនក្នុង React ត្រូវប្រើ Array.map() និងតម្រូវឱ្យមាន key ពិសេសមិនស្ទួនគ្នាលើធាតុមេជានិច្ច។

React.js 11. Forms Handling

11. Forms Handling (Controlled Components)

1. Definition (តើវាជាអ្វី?):

Controlled Component គឺជាទម្រង់គ្រប់គ្រងប្រអប់ Input នៅក្នុង React ដែលតម្លៃរបស់ Input (value) ត្រូវបានភ្ជាប់ និងគ្រប់គ្រងទាំងស្រុងដោយ React State។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ធានាថា React State គឺជាប្រភពទិន្នន័យពិតតែមួយគត់ (Single Source of Truth)។
  • ងាយស្រួលផ្ទៀងផ្ទាត់ទិន្នន័យ (Validation) មុនពេលចុចបញ្ជូន (Submit)។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់គ្រប់ប្រអប់បញ្ចូលទិន្នន័យ Form ទាំងអស់ក្នុងកម្មវិធី React។

4. Syntax (ទម្រង់កូដ Controlled Form):

import { useState } from 'react';

function LoginForm() {
  const [email, setEmail] = useState("");

  const handleSubmit = (e) => {
    e.preventDefault(); // ទប់កុំឱ្យ Refresh ទំព័រ
    alert(`អ៊ីមែល៖ ${email}`);
    setEmail(""); // សម្អាត Input
  };

  return (
    <form onSubmit={handleSubmit}>
      <input value={email} onChange={(e) => setEmail(e.target.value)} />
      <button type="submit">ចូលគណនី</button>
    </form>
  );
}

export default LoginForm;

5. Explanation (ការពន្យល់កូដ):

  • e.preventDefault() ការពារទំព័រមិនឱ្យ Reload ពេលចុច Submit។
  • value={email} និង onChange ភ្ជាប់ប្រអប់ Input ជាមួយ State ទៅវិញទៅមក។

6. Output (លទ្ធផល):

ពេលវាយអ៊ីមែលរួចចុចប៊ូតុង វានឹងលោតផ្ទាំង Alert បញ្ជាក់ និងសម្អាតប្រអប់ Input ឱ្យទទេស្អាតឡើងវិញ។

7. Summary (សង្ខេបមេរៀន)៖ ការគ្រប់គ្រង Form ក្នុង React ត្រូវភ្ជាប់ value ទៅ State និងប្រើ e.preventDefault() ដើម្បីទប់ស្កាត់ការ Refresh ទំព័រ។

12. LocalStorage & Data Persistence

1. Definition (តើវាជាអ្វី?):

LocalStorage គឺជា Web Storage API របស់ Browser សម្រាប់រក្សាទុកទិន្នន័យជាគូ Key-Value String ជាអចិន្ត្រៃយ៍ ទោះបីជាបិទ ឬ Refresh Browser ក៏ទិន្នន័យមិនបាត់បង់ដែរ។

2. Purpose (មេតូដសំខាន់ៗ):

  • localStorage.setItem(key, JSON.stringify(data)) បម្លែងជា String រួចរក្សាទុក។
  • JSON.parse(localStorage.getItem(key)) ទាញទិន្នន័យមកបម្លែងជា Object/Array វិញ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់រក្សាទុកទិន្នន័យកន្ត្រកទំនិញ, បញ្ជីការងារ Todo និងការកំណត់ Dark Mode ក្នុងម៉ាស៊ីនអ្នកប្រើប្រាស់។

4. Syntax (ទម្រង់កូដប្រើ LocalStorage ជាមួយ useState):

import { useState, useEffect } from 'react';

function NameStorage() {
  const [name, setName] = useState(() => {
    return localStorage.getItem("username") || "";
  });

  useEffect(() => {
    localStorage.setItem("username", name);
  }, [name]);

  return (
    <input value={name} onChange={(e) => setName(e.target.value)} />
  );
}

export default NameStorage;

5. Explanation (ការពន្យល់កូដ):

  • តម្លៃដើមរបស់ State ត្រូវបានទាញចេញពី LocalStorage តាមរយៈ getItem ពេលបើកទំព័រដំបូង។
  • useEffect ធ្វើបច្ចុប្បន្នភាពទិន្នន័យក្នុង LocalStorage ស្វ័យប្រវត្តិតាមរយៈ setItem រាល់ពេល name ប្តូរ។

6. Output (លទ្ធផល):

នៅពេលវាយឈ្មោះក្នុងប្រអប់ ហើយចុច Refresh ទំព័រ ឈ្មោះនោះនៅតែរក្សាទុកដដែល មិនបាត់បង់ឡើយ។

7. Summary (សង្ខេបមេរៀន)៖ LocalStorage រក្សាទុកទិន្នន័យអចិន្ត្រៃយ៍លើ Client Browser។ ការប្រើរួមគ្នាជាមួយ JSON.stringify() និង JSON.parse() អនុញ្ញាតឱ្យរក្សាទុកទិន្នន័យស្មុគស្មាញបានយ៉ាងងាយ។

React.js 13. React Hooks

13. React Hooks (useEffect & useRef)

1. Definition (តើវាជាអ្វី?):

React Hooks គឺជាអនុគមន៍ពិសេសសម្រាប់គ្រប់គ្រងមុខងារកម្រិតខ្ពស់ ដោយ useEffect ប្រើសម្រាប់គ្រប់គ្រង Side Effects (ដូចជាការទាញទិន្នន័យ API) និង useRef ប្រើសម្រាប់ចាប់យក DOM ដោយផ្ទាល់។

2. Purpose (ភាពខុសគ្នានៃ Hooks ទាំងពីរ):

  • useEffect: ដំណើរការកូដពេល Component បង្ហាញលើកដំបូង (Mount) ឬពេល State ក្នុង Dependency Array [ ] ផ្លាស់ប្តូរ។
  • useRef: រក្សាតម្លៃអថេរដែលមិនធ្វើឱ្យ Component Re-render និងអាចបញ្ជា .focus() លើប្រអប់ Input បាន។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើ useEffect ពេល Fetch API ឬកំណត់ Timer និងប្រើ useRef ពេលចង់ឱ្យ Cursor លោតចូល Input ស្វ័យប្រវត្តិ។

4. Syntax (ទម្រង់កូដ useEffect និង useRef):

import { useEffect, useRef } from 'react';

function AutoInput() {
  const inputRef = useRef(null);

  useEffect(() => {
    inputRef.current.focus(); // Cursor លោតចូល Input ពេលបើកទំព័រដំបូង
  }, []);

  return (
    <input ref={inputRef} placeholder="វាយទីនេះ..." />
  );
}

export default AutoInput;

5. Explanation (ការពន្យល់កូដ):

  • [] (Empty Dependency) បញ្ជាក់ថាកូដក្នុង useEffect ដំណើរការតែម្តងគត់ពេលបើកទំព័រដំបូង។
  • ref={inputRef} ចាប់យកធាតុ DOM ពិតប្រាកដមកគ្រប់គ្រង។

6. Output (លទ្ធផល):

នៅពេលបើកទំព័រភ្លាម Cursor នឹងលោតចូលក្នុងប្រអប់ Input ស្វ័យប្រវត្តិតែម្តង។

7. Summary (សង្ខេបមេរៀន)៖ useEffect ដោះស្រាយការងារ Side Effects ក្នុង Lifecycle របស់ Component រីឯ useRef ចាប់យក DOM ផ្ទាល់ដោយមិនបង្កឱ្យ Re-render។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 16

14. React Router (ការប្តូរទំព័រក្នុង SPA)

1. Definition (តើវាជាអ្វី?):

React Router (react-router-dom) គឺជាបណ្ណាល័យសម្រាប់គ្រប់គ្រងការផ្លាស់ប្តូរទំព័រ (Client-Side Routing) ក្នុងកម្មវិធី React ដោយមិនបាច់ Reload ទំព័រឡើងវិញឡើយ។

2. Purpose (សមាសភាគស្នូល):

  • <BrowserRouter> រុំព័ទ្ធកម្មវិធីទាំងមូលដើម្បីបើកដំណើរការ Routing។
  • <Routes> និង <Route> កំណត់ផ្លូវ Path និង Component ដែលត្រូវបង្ហាញ។
  • <Link to="..."> ប្រើជំនួសស្លាក <a> ដើម្បីប្តូរទំព័រដោយមិនវិលកង់ Reload។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលគេហទំព័រមានច្រើនទំព័រ ដូចជាទំព័រដើម (/), ទំព័រវគ្គសិក្សា (/courses) និងទំព័រទំនាក់ទំនង (/contact)។

4. Syntax (ទម្រង់កូដ React Router):

import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';

function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">ទំព័រដើម</Link> | <Link to="/about">អំពីយើង</Link>
      </nav>
      <Routes>
        <Route path="/" element={<h2>ទំព័រដើម</h2>} />
        <Route path="/about" element={<h2>អំពីយើង</h2>} />
      </Routes>
    </BrowserRouter>
  );
}

export default App;

5. Explanation (ការពន្យល់កូដ):

  • <Link to="/about"> ផ្លាស់ប្តូរ URL ភ្លាមៗដោយគ្មានការ Reload ទំព័រ។
  • <Route path="/about" ...> ពិនិត្យមើល URL និងបង្ហាញ Component ដែលត្រូវគ្នា។

6. Output (លទ្ធផល):

អ្នកប្រើប្រាស់អាចចុចប្តូរទំព័រទៅមកបានក្នុងល្បឿនលឿនដូចកម្មវិធី Desktop។

7. Summary (សង្ខេបមេរៀន)៖ React Router អនុញ្ញាតឱ្យសាងសង់ Single Page Application ដែលមានច្រើនទំព័រប្រកបដោយល្បឿនលឿន ដោយប្រើ <Link> និង <Routes>។

15. API Integration (ការទាញទិន្នន័យពី Server)

1. Definition (តើវាជាអ្វី?):

API Integration គឺជាការតភ្ជាប់កម្មវិធី React ទៅកាន់ Backend Server ដើម្បីទាញយកទិន្នន័យពិត (JSON) មកបង្ហាញលើ UI តាមរយៈអនុគមន៍ fetch() ឬ async/await។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • បង្ហាញទិន្នន័យជាក់ស្តែងដែលផ្ទុកលើ Database (ដូចជាបញ្ជីអត្ថបទ ឬផលិតផល)។
  • គ្រប់គ្រងស្ថានភាព Loading និង Error ឱ្យអ្នកប្រើប្រាស់ដឹងមុនពេលទិន្នន័យមកដល់។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើរាល់ពេលដែលកម្មវិធីត្រូវការទាញទិន្នន័យពី RESTful API ខាងក្រៅ។

4. Syntax (ទម្រង់កូដ Fetch API ជាមួយ useEffect):

import { useState, useEffect } from 'react';

function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch("https://jsonplaceholder.typicode.com/users")
      .then((res) => res.json())
      .then((data) => {
        setUsers(data);
        setLoading(false);
      });
  }, []);

  if (loading) return <p>កំពុងទាញទិន្នន័យ...</p>;

  return (
    <ul>
      {users.map(({ id, name }) => (
        <li key={id}>{name}</li>
      ))}
    </ul>
  );
}

export default UserList;

5. Explanation (ការពន្យល់កូដ):

  • fetch(...) ទាញយកទិន្នន័យពី URL រួចបម្លែងជា JSON តាមរយៈ res.json()។
  • setLoading(false) បិទស្ថានភាព Loading នៅពេលទិន្នន័យមកដល់ពេញលេញ។

6. Output (លទ្ធផល):

បង្ហាញពាក្យ "កំពុងទាញទិន្នន័យ..." បន្តិច រួចបង្ហាញបញ្ជីឈ្មោះអ្នកប្រើប្រាស់ទាំង ១០ នាក់ពី Server។

7. Summary (សង្ខេបមេរៀន)៖ ការទាញទិន្នន័យ API ក្នុង React ត្រូវធ្វើឡើងក្នុង useEffect និងប្រើប្រាស់ State សម្រាប់រក្សាទុកទិន្នន័យព្រមទាំង Loading State។

16. React Project Architecture & Modular CSS

1. Definition (តើវាជាអ្វី?):

React Project Architecture គឺជាការរៀបចំរចនាសម្ព័ន្ធ Folders និង Files ក្នុងថត src/ ឱ្យមានស្តង់ដារ និងការប្រើប្រាស់ CSS ដាច់ដោយឡែក (Vanilla CSS ឬ CSS Modules) ដោយមិនពឹងផ្អែកលើ Tailwind CSS។

2. Purpose (ហេតុអ្វីត្រូវរៀបចំ Folder ឱ្យមានរបៀប?):

  • បែងចែកដាច់ពីគ្នារវាង Reusable Components (components/) និងទំព័រធំៗ (pages/)។
  • ងាយស្រួលធ្វើការងារជាក្រុម និងស្វែងរក File ពេល Project កាន់តែធំ។

3. When to Use (តើប្រើនៅពេលណា?):

អនុវត្តនៅគ្រប់ Project React ជាក់ស្តែងទាំងអស់។

4. Syntax (រចនាសម្ព័ន្ធ Folder ស្តង់ដារ):

src/
├── assets/         # រូបភាព និង Icons
├── components/     # បំណែក UI ប្រើឡើងវិញបាន (Navbar.jsx, Card.jsx)
├── pages/          # ទំព័រ Route ពេញលេញ (Home.jsx, About.jsx)
├── services/       # ឯកសារទាញយក API (api.js)
├── App.jsx         # Component មេគ្រប់គ្រង Layout & Routes
├── main.jsx        # ចំណុចចាប់ផ្តើមភ្ជាប់ DOM
└── style.css       # ឯកសារ CSS ស្តង់ដាររួម

5. Explanation (ការពន្យល់រចនាសម្ព័ន្ធ):

  • components/ ផ្ទុកតែបំណែក UI តូចៗដែលគ្មានទំព័រដាច់ដោយឡែក។
  • pages/ ផ្ទុកទំព័រដែលត្រូវភ្ជាប់ជាមួយ React Router។

6. Output (លទ្ធផល):

ទទួលបានគ្រោងឆ្អឹង Project ស្អាត ងាយស្រួលពង្រីកមុខងារ និងងាយស្រួល Deploy លើ Vercel។

7. Summary (សង្ខេបមេរៀន)៖ ការរៀបចំ Folder Architecture ច្បាស់លាស់ជួយឱ្យ Codebase ស្អាត ងាយស្រួល Maintain និងបង្កើនប្រសិទ្ធភាពការងារក្នុងក្រុម។

17. Practical Project: Task Manager (Pure React & CSS)

1. Project Overview (សេចក្តីពិពណ៌នាគម្រោង):

បង្កើតកម្មវិធីគ្រប់គ្រងកិច្ចការសិក្សាពេញលេញ ដោយប្រើប្រាស់ React សុទ្ធសាធ រួមមាន useState, useEffect, Destructuring, LocalStorage និងការរចនាដោយ CSS ស្តង់ដារ (មិនប្រើ Tailwind CSS ឡើយ)។

4. Complete Code (កូដពេញលេញសម្រាប់អនុវត្ត):

import { useState, useEffect } from 'react';

function TaskManager() {
  const [tasks, setTasks] = useState(() => {
    const saved = localStorage.getItem("tasks_db");
    return saved ? JSON.parse(saved) : [];
  });
  const [text, setText] = useState("");

  useEffect(() => {
    localStorage.setItem("tasks_db", JSON.stringify(tasks));
  }, [tasks]);

  const addTask = (e) => {
    e.preventDefault();
    if (!text.trim()) return;
    setTasks([...tasks, { id: Date.now(), title: text }]);
    setText("");
  };

  const deleteTask = (id) => setTasks(tasks.filter((item) => item.id !== id));

  return (
    <div style={{ maxWidth: '400px', margin: '0 auto', padding: '20px' }}>
      <h2>កម្មវិធីគ្រប់គ្រងកិច្ចការសិក្សា</h2>
      <form onSubmit={addTask}>
        <input value={text} onChange={(e) => setText(e.target.value)} />
        <button>បន្ថែម</button>
      </form>
      <ul>
        {tasks.map(({ id, title }) => (
          <li key={id}>
            {title} <button onClick={() => deleteTask(id)}>លុប</button>
          </li>
        ))}
      </ul>
    </div>
  );
}

export default TaskManager;
7. Summary (សង្ខេបមេរៀន)៖ គម្រោងនេះរួមបញ្ចូលគ្នានូវ State, Events, Lists, Destructuring និង LocalStorage ដែលជាមូលដ្ឋានគ្រឹះពិតប្រាកដក្នុងការបង្កើតកម្មវិធី React អាជីព។

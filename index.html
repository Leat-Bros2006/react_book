React.js Learning Book 01. Introduction to React.js

01. Introduction to React.js

1. Definition (តើវាជាអ្វី?):

React.js គឺជា JavaScript Library មួយដែលត្រូវបានអភិវឌ្ឍដោយ Meta (Facebook) សម្រាប់បង្កើត User Interface (UI) លើ Web Application ជាពិសេសគឺ Single Page Applications (SPA)។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ធ្វើឱ្យការរៀបចំ UI មានភាពងាយស្រួល និងបត់បែនតាមរយៈ Component-Based Architecture។
  • បង្កើនល្បឿន Render និង Performance ដោយប្រើប្រាស់ Virtual DOM។
  • អាច Re-use កូដ UI ឡើងវិញបាន ជួយកាត់បន្ថយការសរសេរកូដដដែលៗ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើប្រាស់នៅពេលបង្កើត Web App ដែលមានភាពស្មុគស្មាញ មាន Dynamic Data ច្រើន និងត្រូវការភាពរហ័សរហួនដូចជា Dashboard, Social Media, E-commerce ឬ SaaS Applications។

4. Syntax (ឧទាហរណ៍ទម្រង់កូដ React ដំបូង):

import React from 'react';

function App() {
  return (
    <div className="p-6 bg-sky-50 rounded-xl">
      <h1 className="text-2xl font-bold text-sky-600">សួស្តី React.js!</h1>
      <p className="text-slate-600">សូមស្វាគមន៍មកកាន់ការសិក្សា React.js ពីមូលដ្ឋាន!</p>
    </div>
  );
}

export default App;

5. Explanation (ការពន្យល់កូដ):

  • function App() គឺជា Functional Component ដែលប្រគល់មកវិញនូវធាតុ UI។
  • className ត្រូវបានប្រើប្រាស់ជំនួស class នៅក្នុង HTML ស្តង់ដារ ដើម្បីដាក់ Tailwind CSS។
  • export default App គឺដើម្បីឱ្យ File ផ្សេងទៀតអាច Import Component នេះទៅប្រើបាន។

6. Output (លទ្ធផល):

បង្ហាញប្រអប់ពណ៌ខៀវខ្ចីដែលមានចំណងជើង "សួស្តី React.js!" និងអត្ថបទស្វាគមន៍នៅលើផ្ទាំង Web Browser។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើត Functional Component មួយឈ្មោះថា Header ដែលបង្ហាញឈ្មោះសៀវភៅ និងឈ្មោះរបស់អ្នករៀបចំ។

React.js Learning Book 02. React Development Environment

02. React Development Environment (Vite & Tailwind)

1. Definition (តើវាជាអ្វី?):

React Development Environment គឺជាការរៀបចំកម្មវិធី និងឧបករណ៍ចាំបាច់នានា (Node.js, VS Code, Vite Build Tool និង Tailwind CSS) នៅលើកុំព្យូទ័រ (Windows ឬ macOS) ដើម្បីបង្កើត និងដំណើរការ Project React បានយ៉ាងរហ័ស។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • Vite ផ្តល់នូវល្បឿនចាប់ផ្តើម Server លឿនបំផុត និងគាំទ្រ Hot Module Replacement (HMR) កែភ្លាមឃើញភ្លាម។
  • Tailwind CSS អនុញ្ញាតឱ្យយើងរចនា UI ដោយប្រើ Utility Classes ផ្ទាល់ក្នុង JSX ដោយមិនបាច់សរសេរ CSS វែងឆ្ងាយ។
  • Node.js & npm ជួយគ្រប់គ្រង និងដំឡើង Packages ឬ Libraries បន្ថែម (ដូចជា React Router, Lucide Icons)។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើប្រាស់នៅរាល់ពេលចាប់ផ្តើមបង្កើត Project React ថ្មីនៅក្នុងម៉ាស៊ីនកុំព្យូទ័រផ្ទាល់ខ្លួន។

4. Syntax (របៀបបង្កើត Project React ជាមួយ Vite & Tailwind CSS v4):

# 1. បង្កើត Project React ថ្មីជាមួយ Vite (Windows & macOS Terminal)
npm create vite@latest my-react-app -- --template react
cd my-react-app
npm install

# 2. ដំឡើង Tailwind CSS សម្រាប់ Vite
npm install tailwindcss @tailwindcss/vite

# 3. បន្ថែមក្នុងឯកសារ src/index.css
@import "tailwindcss";

# 4. ដំណើរការ Development Server
npm run dev

5. Explanation (ការពន្យល់កូដ):

  • npm create vite@latest ជាពាក្យបញ្ជាទាញយកគ្រោងឆ្អឹង React ថ្មីចុងក្រោយបង្អស់។
  • npm install សម្រាប់ទាញយក Folder node_modules ដែលផ្ទុកបណ្ណាល័យទាំងអស់របស់ React។
  • @import "tailwindcss"; បើកដំណើរការគ្រប់ Utility Classes ទាំងអស់របស់ Tailwind នៅក្នុង Project។
  • npm run dev បើកដំណើរការវេបសាយនៅលើអាសយដ្ឋាន http://localhost:5173។

6. Output (លទ្ធផល):

Terminal នឹងបង្ហាញតំណភ្ជាប់ http://localhost:5173/ ហើយពេលបើកក្នុង Browser នឹងឃើញទំព័រដើមរបស់ Vite + React។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើត Project ថ្មោះថា react-tailwind-book ដំឡើង Tailwind CSS រួចកែប្រែអត្ថបទក្នុង App.jsx ឱ្យចេញពណ៌ខៀវធំចំកណ្តាលអេក្រង់។

React.js Learning Book 03. JSX Fundamentals

03. JSX Fundamentals

1. Definition (តើវាជាអ្វី?):

JSX (JavaScript XML) គឺជា Syntax Extension របស់ JavaScript ដែលអនុញ្ញាតឱ្យយើងសរសេរកូដមានទម្រង់ដូច HTML ដោយផ្ទាល់នៅក្នុងឯកសារ JavaScript/React[cite: 2]។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ធ្វើឱ្យការបង្កើតរចនាសម្ព័ន្ធ UI ងាយស្រួលមើល និងងាយសរសេរដូចការសរសេរកូដ HTML ធម្មតា។
  • អនុញ្ញាតឱ្យបញ្ចូលតម្លៃអថេរ (Variables), គណនាលេខ ឬហៅអនុគមន៍ JavaScript នៅក្នុង HTML តាមរយៈសញ្ញា { }[cite: 2]។
  • ការពារសុវត្ថិភាពពីការវាយប្រហារ XSS (Injection Attacks) ដោយស្វ័យប្រវត្តិមុនពេល Render។

3. When to Use (ច្បាប់សំខាន់ៗនៃ JSX):

  • Single Root Element: ត្រូវតែមាន Parent Element តែមួយគត់រុំព័ទ្ធពីក្រៅ (ឬប្រើ Fragment <>...</>)[cite: 2]។
  • Close All Tags: ស្លាកទាំងអស់ត្រូវតែបិទជានិច្ច រួមទាំង <img />, <br />, <input />[cite: 2]។
  • CamelCase Attributes: ប្រើប្រាស់ className, htmlFor, onClick ជំនួសឱ្យឈ្មោះក្នុង HTML ធម្មតា[cite: 2]។

4. Syntax (ឧទាហរណ៍ការប្រើប្រាស់ JSX):

function CourseBanner() {
  const courseTitle = "React.js & Tailwind CSS";
  const price = 45;

  return (
    <>
      <div className="p-4 bg-white border rounded-lg shadow-sm">
        <h2 className="text-xl font-bold">វគ្គសិក្សា៖ {courseTitle}</h2>
        <p>តម្លៃសិក្សា៖ ${price} (បញ្ចុះតម្លៃនៅសល់ ${price - 10})</p>
        <input type="text" placeholder="បញ្ចូលឈ្មោះសិស្ស..." />
      </div>
    </>
  );
}

5. Explanation (ការពន្យល់កូដ):

  • <> ... </> គឺជា React Fragment ប្រើសម្រាប់រុំព័ទ្ធធាតុដោយមិនបង្កើត <div> លើសនៅក្នុង DOM។
  • {courseTitle} និង {price - 10} គឺជាការបង្កប់ JavaScript Expression នៅក្នុង JSX។
  • <input ... /> ត្រូវបានបិទដោយសញ្ញា /> យ៉ាងត្រឹមត្រូវតាមក្បួន JSX។

6. Output (លទ្ធផល):

បង្ហាញចំណងជើង "វគ្គសិក្សា៖ React.js & Tailwind CSS", អត្ថបទគណនាតម្លៃ "$45 (បញ្ចុះតម្លៃនៅសល់ $35)" និងប្រអប់ Input មួយ។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើត Component StudentProfile ដែលមានអថេរ fullName, birthYear និងគណនាអាយុបច្ចុប្បន្នក្នុងសញ្ញា {2026 - birthYear}។

React.js Learning Book 04. Array & Object Destructuring

04. Array & Object Destructuring (ES6+)

1. Definition (តើវាជាអ្វី?):

Destructuring គឺជាមុខងាររបស់ JavaScript (ES6+) ដែលអនុញ្ញាតឱ្យយើងបំបែក ឬទាញយកតម្លៃចេញពីក្នុង Array (តាមលំដាប់ Index) ឬចេញពីក្នុង Object (តាមឈ្មោះ Property Key) មកដាក់ក្នុង Variables ផ្ទាល់តែម្តង។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • Array Destructuring គឺជាមូលដ្ឋានគ្រឹះនៃការប្រើប្រាស់ React Hooks ដូចជា const [count, setCount] = useState(0)។
  • Object Destructuring ជួយឱ្យយើងទាញយកតម្លៃពី props ឬទិន្នន័យ API ដោយមិនបាច់សរសេរ props.name ឬ user.email ដដែលៗ។
  • អាចកំណត់តម្លៃដើម (Default Values) និងការប្តូរឈ្មោះអថេរ (Alias) បានយ៉ាងងាយស្រួល។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើប្រាស់រាល់ពេលហៅប្រើ useState, ពេលទទួល props នៅក្នុងក្បាលអនុគមន៍ Component, និងពេលទាញទិន្នន័យ Object ពី API។

4. Syntax (ឧទាហរណ៍ Array & Object Destructuring):

// 1. Array Destructuring (ចាប់យកតាមលំដាប់ទីតាំងទី 0, ទី 1)
const scores = [95, 88, 76];
const [mathScore, webScore] = scores;

// 2. Object Destructuring (ចាប់យកតាមឈ្មោះ Key និងកំណត់ Default Value)
const instructor = {
  fullName: "លាត ប្រុស",
  skill: "React & Tailwind",
  province: "Siem Reap"
};
const { fullName, skill, role = "Senior Teacher" } = instructor;

function InstructorCard() {
  return <p>{fullName} ({role}) - ជំនាញ៖ {skill} | ពិន្ទុ៖ {mathScore}</p>;
}

5. Explanation (ការពន្យល់កូដ):

  • const [mathScore, webScore] = scores ប្រើសញ្ញាគ្នៀប [ ] សម្រាប់បំបែក Array ដោយ mathScore ទទួលបានតម្លៃ 95។
  • const { fullName, skill } = instructor ប្រើសញ្ញាខ្នងក្រពើ { } សម្រាប់បំបែក Object តាមឈ្មោះ Key ផ្ទាល់។
  • role = "Senior Teacher" គឺជាការផ្តល់ Default Value ប្រសិនបើក្នុង Object គ្មាន Key ឈ្មោះ role។

6. Output (លទ្ធផល):

បង្ហាញអត្ថបទ៖ "លាត ប្រុស (Senior Teacher) - ជំនាញ៖ React & Tailwind | ពិន្ទុ៖ 95"។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើត Object product = { id: 101, title: "MacBook Pro", price: 1499 } រួចប្រើ Object Destructuring ទាញយកតម្លៃមកបង្ហាញក្នុង Component។

React.js Learning Book 05. React Components (Export & Import)

05. React Components (ការបង្កើត, Export និង Import)

1. Definition (តើវាជាអ្វី?):

React Component គឺជាអនុគមន៍ JavaScript ឯករាជ្យ (ឈ្មោះផ្តើមដោយអក្សរធំ PascalCase) ដែលបំបែក UI ធំមួយឱ្យទៅជាបំណែកតូចៗ (ដូចជា Navbar.jsx, ProductCard.jsx, Footer.jsx) ហើយភ្ជាប់គ្នាតាមរយៈការធ្វើ Export និង Import។

2. Purpose (ភាពខុសគ្នារវាង Default Export និង Named Export):

  • Default Export (export default Name): ក្នុង 1 File អាចមាន Default Export តែមួយគត់។ ពេល Import មិនបាច់ដាក់សញ្ញា { } ទេ។
  • Named Export (export function Name): ក្នុង 1 File អាច Export បានច្រើន Components។ ពេល Import ត្រូវតែដាក់ក្នុងសញ្ញា { Name } ឱ្យត្រូវឈ្មោះដើម។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើ Default Export សម្រាប់ Component ចម្បងប្រចាំឯកសារនីមួយៗ និងប្រើ Named Export សម្រាប់បណ្តុំ Buttons, Icons ឬ Helper Components តូចៗ។

4. Syntax (ឧទាហរណ៍ការធ្វើ Export និង Import រវាង 2 ឯកសារ):

// ឯកសារទី ១៖ src/components/Button.jsx
export function OutlineBtn() {
  return <button className="border px-4 py-2 rounded">អានបន្ថែម</button>;
}

export default function PrimaryBtn() {
  return <button className="bg-sky-600 text-white px-4 py-2 rounded">ទិញឥឡូវនេះ</button>;
}

// ឯកសារទី ២៖ src/App.jsx (ការហៅមកប្រើប្រាស់)
import PrimaryBtn, { OutlineBtn } from './components/Button';

export default function App() {
  return (
    <div className="flex gap-3">
      <PrimaryBtn />
      <OutlineBtn />
    </div>
  );
}

5. Explanation (ការពន្យល់កូដ):

  • export function OutlineBtn ជា Named Export ដូច្នេះពេល Import ត្រូវដាក់ក្នុង { OutlineBtn }។
  • export default function PrimaryBtn ជា Default Export ដូច្នេះពេល Import សរសេរឈ្មោះផ្ទាល់ import PrimaryBtn។
  • <PrimaryBtn /> គឺជាការហៅ Component មកបង្ហាញក្នុងទម្រង់ជា JSX Tag។

6. Output (លទ្ធផល):

បង្ហាញប៊ូតុងចំនួន 2 នៅជិតគ្នា៖ ប៊ូតុងពណ៌ខៀវ "ទិញឥឡូវនេះ" និងប៊ូតុងស៊ុម "អានបន្ថែម"។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើតឯកសារ Navbar.jsx និង Footer.jsx ដាច់ដោយឡែកពីគ្នា រួច Import ចូលទៅក្នុងឯកសារ App.jsx។

React.js Learning Book 06. Props

06. Props (ការបញ្ជូនទិន្នន័យរវាង Components)

1. Definition (តើវាជាអ្វី?):

Props (ពាក្យកាត់មកពី Properties) គឺជាយន្តការសម្រាប់បញ្ជូនទិន្នន័យពី Parent Component (មេ) ចុះទៅកាន់ Child Component (កូន) តាមរយៈ JSX Attributes។ Props គឺជាទិន្នន័យប្រភេទ Read-Only (កូនមិនអាចកែប្រែតម្លៃ Props ដោយផ្ទាល់បានទេ)។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ធ្វើឱ្យ Component តែមួយអាចបង្ហាញទិន្នន័យខុសៗគ្នាបានរាប់រយដង (Dynamic & Reusable Component)។
  • អាចបញ្ជូនទិន្នន័យបានគ្រប់ប្រភេទ៖ អត្ថបទ (String), លេខ (Number), Boolean, Array, Object ឬអនុគមន៍ (Function)។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលយើងមានទម្រង់ UI ដូចគ្នា (ដូចជាកាតផលិតផល កាតសិស្ស ឬប៊ូតុង) តែចង់បញ្ជូនឈ្មោះ រូបភាព និងតម្លៃខុសៗគ្នាពី Component មេ។

4. Syntax (ការទទួល Props ដោយប្រើ Object Destructuring):

// Child Component: ទទួល Props តាមរយៈ Destructuring
function CourseCard({ title, mentor, price = 0 }) {
  return (
    <div className="p-4 border rounded-xl shadow-sm bg-white">
      <h3 className="font-bold text-lg text-slate-800">{title}</h3>
      <p className="text-sm text-slate-500">បង្រៀនដោយ៖ {mentor}</p>
      <span className="text-sky-600 font-semibold">${price}</span>
    </div>
  );
}

// Parent Component: បញ្ជូនតម្លៃ Props ទៅឱ្យកូន
export default function App() {
  return (
    <div className="grid grid-cols-2 gap-4">
      <CourseCard title="React.js Masterclass" mentor="លាត ប្រុស" price={50} />
      <CourseCard title="Tailwind CSS Design" mentor="លាត ប្រុស" price={35} />
    </div>
  );
}

5. Explanation (ការពន្យល់កូដ):

  • { title, mentor, price = 0 } បំបែក Props Object ផ្ទាល់នៅក្នុងប៉ារ៉ាម៉ែត្រអនុគមន៍។
  • price={50} ការបញ្ជូនតម្លៃជាលេខ (Number) ត្រូវដាក់ក្នុងសញ្ញា { } រីឯអត្ថបទដាក់ក្នុង " "។

6. Output (លទ្ធផល):

បង្ហាញប្រអប់វគ្គសិក្សា 2 ក្នុងជួរតែមួយ ដែលមានចំណងជើង និងតម្លៃខុសគ្នា ($50 និង $35)។

7. Practice (លំហាត់អនុវត្តទី ១):

ចូរបង្កើត Component ProductItem ដែលទទួល Props ចំនួន 3 គឺ name, category និង inStock រួចហៅប្រើ 3 ដងក្នុង App.jsx។

07. State and useState Hook

1. Definition (តើវាជាអ្វី?):

State គឺជាអង្គចងចាំផ្ទៃក្នុង (Internal Memory) របស់ Component សម្រាប់ផ្ទុកទិន្នន័យដែលអាចផ្លាស់ប្តូរតាមពេលវេលា។ នៅពេលតម្លៃ State ផ្លាស់ប្តូរ React នឹងធ្វើការគូសបង្ហាញ (Re-render) UI ថ្មីដោយស្វ័យប្រវត្តិ។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • អថេរ JavaScript ធម្មតា (let count = 0) ពេលប្តូរតម្លៃ មិនអាចធ្វើឱ្យអេក្រង់ UI ផ្លាស់ប្តូរតាមឡើយ។
  • useState ផ្តល់នូវអថេរផ្ទុកតម្លៃបច្ចុប្បន្ន និងអនុគមន៍ Setter សម្រាប់កែប្រែតម្លៃ និងបញ្ជាឱ្យ Component Re-render។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់រាប់ចំនួនទំនិញក្នុងកន្ត្រក (Cart Counter), ការបិទ/បើកផ្ទាំង Modal, ការប្តូរ Dark/Light Mode និងការរក្សាទុកអត្ថបទដែលអ្នកប្រើប្រាស់វាយក្នុង Form។

4. Syntax (ឧទាហរណ៍ការប្រើប្រាស់ useState):

import { useState } from 'react';

export default function CounterBox() {
  const [count, setCount] = useState(0);

  return (
    <div className="p-5 bg-white border rounded-xl flex items-center gap-4">
      <button onClick={() => setCount(count - 1)} className="px-3 py-1 bg-slate-200 rounded">-</button>
      <span className="text-xl font-bold">ចំនួន៖ {count}</span>
      <button onClick={() => setCount(count + 1)} className="px-3 py-1 bg-sky-600 text-white rounded">+</button>
    </div>
  );
}

5. Explanation (ការពន្យល់កូដ):

  • import { useState } from 'react' នាំចូល Hook useState ពីបណ្ណាល័យ React។
  • const [count, setCount] = useState(0) បង្កើត State ឈ្មោះ count ដែលមានតម្លៃចាប់ផ្តើមស្មើ 0។
  • setCount(count + 1) បង្កើនតម្លៃ count ម្តង 1 និងធ្វើបច្ចុប្បន្នភាពលេខនៅលើអេក្រង់ភ្លាមៗ។

6. Output (លទ្ធផល):

បង្ហាញប៊ូតុងដក (-) អត្ថបទ "ចំនួន៖ 0" និងប៊ូតុងបូក (+) ដែលអាចចុចបន្ថែម ឬបន្ថយលេខបានដោយផ្ទាល់។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើតប៊ូតុង Toggle មួយដែលប្រើ const [isShow, setIsShow] = useState(true) ដើម្បីបង្ហាញ ឬលាក់ប្រអប់អត្ថបទសម្ងាត់។

08. Event Handling (ការគ្រប់គ្រងព្រឹត្តិការណ៍)

1. Definition (តើវាជាអ្វី?):

Event Handling គឺជាការសរសេរអនុគមន៍ដើម្បីឆ្លើយតបទៅនឹងសកម្មភាពរបស់អ្នកប្រើប្រាស់នៅលើគេហទំព័រ ដូចជាការចុច Mouse (onClick), ការវាយអក្សរក្នុងប្រអប់ (onChange) និងការបញ្ជូនទម្រង់បែបបទ (onSubmit)។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ធ្វើឱ្យគេហទំព័រមានអន្តរកម្ម (Interactive) អាចទទួលការបញ្ជាពីអ្នកប្រើប្រាស់បាន។
  • ភ្ជាប់សកម្មភាពរបស់អ្នកប្រើប្រាស់ទៅនឹងការកែប្រែទិន្នន័យក្នុង State ឬការហៅទៅកាន់ API។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅលើគ្រប់ប៊ូតុង ប្រអប់ស្វែងរក (Search Input) ទម្រង់ចុះឈ្មោះ និងម៉ឺនុយទាំងអស់នៅក្នុងកម្មវិធី React។

4. Syntax (ឧទាហរណ៍ការប្រើប្រាស់ onClick និង onChange):

import { useState } from 'react';

export default function SearchBox() {
  const [keyword, setKeyword] = useState("");

  const handleAlert = () => {
    alert(`អ្នកកំពុងស្វែងរកពាក្យ៖ ${keyword}`);
  };

  return (
    <div className="flex gap-2">
      <input
        type="text"
        onChange={(e) => setKeyword(e.target.value)}
        placeholder="វាយពាក្យស្វែងរក..."
        className="border p-2 rounded"
      />
      <button onClick={handleAlert} className="bg-sky-600 text-white px-4 rounded">
        ស្វែងរក
      </button>
    </div>
  );
}

5. Explanation (ការពន្យល់កូដ):

  • e.target.value ចាប់យកតួអក្សរដែលអ្នកប្រើប្រាស់កំពុងវាយបញ្ចូលក្នុងប្រអប់ Input ភ្លាមៗ។
  • onClick={handleAlert} បញ្ជូនឈ្មោះអនុគមន៍ដោយមិនដាក់វង់ក្រចក () ដើម្បីកុំឱ្យវាដំណើរការមុនពេលចុច។

6. Output (លទ្ធផល):

បង្ហាញប្រអប់វាយអក្សរ និងប៊ូតុង "ស្វែងរក" ដែលពេលចុចនឹងលោតផ្ទាំងប្រាប់ពីពាក្យដែលបានវាយ។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើតប៊ូតុងចំនួន 3 (ពណ៌ក្រហម បៃតង ខៀវ) ដែលពេលចុចលើប៊ូតុងណាមួយ នឹងប្តូរពណ៌ផ្ទៃខាងក្រោយរបស់ប្រអប់ Card តាមពណ៌នោះ។

09. Conditional Rendering (ការបង្ហាញ UI តាមលក្ខខណ្ឌ)

1. Definition (តើវាជាអ្វី?):

Conditional Rendering គឺជាការសម្រេចចិត្តបង្ហាញ ឬលាក់ធាតុ JSX ណាមួយដោយផ្អែកលើលក្ខខណ្ឌពិត (true) ឬមិនពិត (false) នៃ State ឬ Props។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • បង្ហាញប៊ូតុង "ចូលគណនី (Login)" ឬ "ចាកចេញ (Logout)" ទៅតាមស្ថានភាពរបស់អ្នកប្រើប្រាស់។
  • បង្ហាញសញ្ញា "កំពុងទាញទិន្នន័យ (Loading...)" មុនពេលទិន្នន័យពី API មកដល់។
  • បង្ហាញស្លាក "អស់ពីស្តុក (Out of Stock)" នៅពេលចំនួនទំនិញស្មើសូន្យ។

3. When to Use (វិធីសាស្ត្រពេញនិយមទាំង 3 ក្នុង React):

  • Ternary Operator (condition ? A : B): ប្រើនៅពេលមានជម្រើស 2 (បើពិតបង្ហាញ A បើមិនពិតបង្ហាញ B)។
  • Logical AND (condition && A): ប្រើនៅពេលចង់បង្ហាញធាតុ A តែនៅពេលលក្ខខណ្ឌពិតប៉ុណ្ណោះ។
  • If / Else Statement: ប្រើនៅខាងក្រៅ JSX មុនបន្ទាត់ return។

4. Syntax (ឧទាហរណ៍ការប្រើ Ternary និង Logical &&):

function UserStatus({ isLoggedIn, unreadCount }) {
  return (
    <div className="p-4 border rounded-lg">
      {isLoggedIn ? (
        <p className="text-emerald-600 font-bold">ស្វាគមន៍ការត្រឡប់មកវិញ!</p>
      ) : (
        <p className="text-rose-600">សូមចូលគណនីជាមុនសិន។</p>
      )}

      {unreadCount > 0 && (
        <span className="text-sm text-sky-600">អ្នកមានសារថ្មីចំនួន {unreadCount}</span>
      )}
    </div>
  );
}

5. Explanation (ការពន្យល់កូដ):

  • isLoggedIn ? ... : ... ពិនិត្យមើលថាបើ isLoggedIn ពិត នឹងបង្ហាញអក្សរពណ៌បៃតង តែបើមិនពិតនឹងបង្ហាញអក្សរពណ៌ក្រហម។
  • unreadCount > 0 && ... បង្ហាញចំនួនសារថ្មីតែនៅពេលដែលមានសារធំជាង 0 ប៉ុណ្ណោះ។

6. Output (លទ្ធផល):

បង្ហាញសារស្វាគមន៍ និងចំនួនសារថ្មី ប្រសិនបើអ្នកប្រើប្រាស់បានចូលគណនីរួចរាល់។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើត Component ExamResult ដែលទទួល Prop score ហើយបង្ហាញពាក្យ "ជាប់ (Pass)" ពណ៌បៃតងបើពិន្ទុ >= 50 ឬ "ធ្លាក់ (Fail)" ពណ៌ក្រហម។

10. Lists and Keys (ការបង្ហាញបញ្ជីទិន្នន័យ)

1. Definition (តើវាជាអ្វី?):

Lists Rendering គឺជាការបម្លែងបណ្តុំទិន្នន័យក្នុង Array ឱ្យទៅជាបញ្ជីនៃធាតុ JSX ដោយប្រើអនុគមន៍ Array.map() រួមជាមួយការផ្តល់តម្លៃសម្គាល់ដាច់ដោយឡែកមួយហៅថា key។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • បង្ហាញបញ្ជីផលិតផល បញ្ជីសិស្ស ឬបញ្ជីអត្ថបទពី Array ដោយមិនបាច់សរសេរកូដ JSX ដដែលៗ។
  • Key Prop ជួយឱ្យ React ស្គាល់អត្តសញ្ញាណធាតុនីមួយៗយ៉ាងច្បាស់នៅពេលមានការបន្ថែម លុប ឬកែប្រែធាតុក្នុងបញ្ជី។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើរាល់ពេលមានទិន្នន័យជាទម្រង់ Array of Objects ហើយចង់គូសបង្ហាញជាតារាង កាត ឬបញ្ជីនៅលើអេក្រង់។

4. Syntax (ឧទាហរណ៍ការប្រើ map() និង Object Destructuring):

const courses = [
  { id: 1, name: "HTML5 & CSS3", hours: 45 },
  { id: 2, name: "JavaScript ES6+", hours: 50 },
  { id: 3, name: "React & Tailwind", hours: 60 }
];

export default function CourseList() {
  return (
    <ul className="space-y-2">
      {courses.map(({ id, name, hours }) => (
        <li key={id} className="p-3 bg-white border rounded-lg flex justify-between">
          <span className="font-semibold">{name}</span>
          <span className="text-sky-600">{hours} ម៉ោង</span>
        </li>
      ))}
    </ul>
  );
}

5. Explanation (ការពន្យល់កូដ):

  • courses.map(...) វិលជុំគ្រប់ធាតុទាំងអស់នៅក្នុង Array courses។
  • ({ id, name, hours }) ប្រើ Object Destructuring ដើម្បីទាញយកតម្លៃពីធាតុនីមួយៗដោយផ្ទាល់។
  • key={id} ផ្តល់លេខសម្គាល់មិនស្ទួនគ្នាទៅឱ្យធាតុមេ <li>។

6. Output (លទ្ធផល):

បង្ហាញបញ្ជីវគ្គសិក្សាទាំង 3 ជួរ ដោយមានឈ្មោះមុខវិជ្ជានៅខាងឆ្វេង និងចំនួនម៉ោងសិក្សានៅខាងស្តាំ។

7. Practice (លំហាត់អនុវត្តទី ២):

ចូរបង្កើត Array students ចំនួន 4 នាក់ រួចប្រើ .map() និង .filter() ដើម្បីបង្ហាញតែសិស្សណាដែលមានពិន្ទុលើសពី 80។

11. Forms Handling

1. Definition (តើវាជាអ្វី?):

Forms Handling នៅក្នុង React គឺជាការគ្រប់គ្រងទិន្នន័យដែលអ្នកប្រើប្រាស់បញ្ចូលក្នុងប្រអប់ Input, Select ឬ Textarea តាមរយៈបច្ចេកទេស Controlled Components (ភ្ជាប់តម្លៃរបស់ Input ទៅនឹង React State)។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • ធ្វើឱ្យ React State ក្លាយជាប្រភពទិន្នន័យពិតតែមួយគត់ (Single Source of Truth) សម្រាប់គ្រប់ប្រអប់ Input។
  • ងាយស្រួលត្រួតពិនិត្យភាពត្រឹមត្រូវនៃទិន្នន័យ (Validation) និងសម្អាតប្រអប់ Input វិញក្រោយពេល Submit។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលបង្កើតទម្រង់ Login, Register, ទម្រង់បន្ថែមផលិតផលថ្មី ឬទម្រង់បញ្ជាទិញទំនិញ។

4. Syntax (ឧទាហរណ៍ Controlled Form Component):

import { useState } from 'react';

export default function EnrollForm() {
  const [studentName, setStudentName] = useState("");

  const handleSubmit = (e) => {
    e.preventDefault(); // ការពារកុំឱ្យ Browser Refresh ទំព័រ
    if (!studentName.trim()) return;
    alert(`ចុះឈ្មោះជោគជ័យ៖ ${studentName}`);
    setStudentName(""); // សម្អាតប្រអប់ Input វិញ
  };

  return (
    <form onSubmit={handleSubmit} className="flex gap-2">
      <input
        type="text"
        value={studentName}
        onChange={(e) => setStudentName(e.target.value)}
        placeholder="ឈ្មោះសិស្ស..."
        className="border p-2 rounded flex-1"
      />
      <button type="submit" className="bg-sky-600 text-white px-4 rounded">រក្សាទុក</button>
    </form>
  );
}

5. Explanation (ការពន្យល់កូដ):

  • e.preventDefault() ទប់ស្កាត់មិនឱ្យទំព័រ Reload នៅពេលចុចប៊ូតុង Submit។
  • value={studentName} និង onChange={...} ភ្ជាប់ប្រអប់ Input ទៅនឹង State ទាំងទៅទាំងមក (Two-way binding)។

6. Output (លទ្ធផល):

ពេលវាយឈ្មោះរួចចុច "រក្សាទុក" វានឹងបង្ហាញសារជោគជ័យ ហើយសម្អាតប្រអប់ Input ឱ្យទំនេរស្អាតវិញ។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើត Form គណនាប្រាក់ខែដែលមាន Input 2 គឺ hours និង rate រួចគណនាប្រាក់សរុបនៅពេលចុច Submit។

12. LocalStorage (ការរក្សាទុកទិន្នន័យក្នុង Browser)

1. Definition (តើវាជាអ្វី?):

LocalStorage គឺជាឃ្លាំងផ្ទុកទិន្នន័យនៅក្នុង Web Browser ដែលអនុញ្ញាតឱ្យគេហទំព័ររក្សាទុកទិន្នន័យជាទម្រង់ Key-Value String បានជាអចិន្ត្រៃយ៍ (ទិន្នន័យមិនបាត់បង់ឡើយទោះបីជាចុច Refresh ឬបិទ Browser បើកមកវិញក៏ដោយ)។

2. Purpose (មុខងារសំខាន់ៗរបស់ LocalStorage):

  • localStorage.setItem("key", JSON.stringify(data)) បម្លែង Array/Object ជា String រួចរក្សាទុក។
  • JSON.parse(localStorage.getItem("key")) ទាញយកទិន្នន័យពី LocalStorage មកបម្លែងជា Array/Object វិញ។
  • localStorage.removeItem("key") លុបទិន្នន័យចេញពីឃ្លាំងផ្ទុក។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់រក្សាទុកបញ្ជីការងារ (Todo List), ទំនិញក្នុងកន្ត្រក (Shopping Cart), ការកំណត់ Dark Mode ឬព័ត៌មានសិស្សដោយមិនទាន់ត្រូវការ Backend Database។

4. Syntax (ការភ្ជាប់ useState ជាមួយ LocalStorage):

import { useState, useEffect } from 'react';

export default function NoteApp() {
  // 1. ទាញទិន្នន័យពី LocalStorage មកដាក់ជាតម្លៃដើមរបស់ State
  const [notes, setNotes] = useState(() => {
    const saved = localStorage.getItem("saved_notes");
    return saved ? JSON.parse(saved) : ["រៀន React.js"];
  });

  // 2. រក្សាទុកទៅក្នុង LocalStorage ស្វ័យប្រវត្តិរាល់ពេល notes ផ្លាស់ប្តូរ
  useEffect(() => {
    localStorage.setItem("saved_notes", JSON.stringify(notes));
  }, [notes]);

  return (
    <button onClick={() => setNotes([...notes, "រៀន LocalStorage"])}>
      ចំនួនកំណត់ហេតុក្នុងម៉ាស៊ីន៖ {notes.length}
    </button>
  );
}

5. Explanation (ការពន្យល់កូដ):

  • JSON.stringify(notes) ចាំបាច់ត្រូវប្រើ ព្រោះ LocalStorage អាចរក្សាទុកបានតែទិន្នន័យជាអត្ថបទ (String) ប៉ុណ្ណោះ។
  • JSON.parse(saved) បម្លែងអត្ថបទ JSON ត្រឡប់មកជា JavaScript Array ដើមវិញ។

6. Output (លទ្ធផល):

រាល់ពេលចុចប៊ូតុង ចំនួនកំណត់ហេតុនឹងកើនឡើង ហើយទោះបីជាចុច Refresh Browser ក៏តម្លៃនោះនៅរក្សាដដែល។

7. Practice (លំហាត់អនុវត្តទី ៣):

ចូរបង្កើតកម្មវិធីរក្សាទុកឈ្មោះ និងលេខទូរស័ព្ទសិស្សចូលក្នុង LocalStorage រួមទាំងប៊ូតុង "លុបទិន្នន័យ"។

React.js Learning Book 13. React Hooks

13. React Hooks (useEffect & useRef)

1. Definition (តើវាជាអ្វី?):

React Hooks គឺជាអនុគមន៍ពិសេសរបស់ React ដែលផ្តើមដោយពាក្យ use។ ក្រៅពី useState គេនិយមប្រើ useEffect សម្រាប់គ្រប់គ្រង Side Effects និង useRef សម្រាប់ចាប់យកធាតុ DOM ដោយផ្ទាល់។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • useEffect: ដំណើរការកូដនៅពេល Component ចាប់ផ្តើមបង្ហាញដំបូង (Mount) ឬនៅពេលអថេរក្នុង Dependency Array [ ] ផ្លាស់ប្តូរ។
  • useRef: ប្រើសម្រាប់បញ្ជាឱ្យ Cursor លោតចូលប្រអប់ Input ស្វ័យប្រវត្តិ (.focus()) ដោយមិនធ្វើឱ្យ Component Re-render។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើ useEffect ពេលទាញទិន្នន័យពី API, កំណត់ document.title, ឬភ្ជាប់ជាមួយ LocalStorage។

4. Syntax (ឧទាហរណ៍ការប្រើប្រាស់ useEffect និង useRef):

import { useEffect, useRef } from 'react';

export default function AutoFocusInput() {
  const inputRef = useRef(null);

  useEffect(() => {
    // ដំណើរការតែម្តងគត់ពេលបើកទំព័រដំបូង
    inputRef.current.focus();
  }, []);

  return (
    <input
      ref={inputRef}
      type="text"
      placeholder="Cursor លោតចូលទីនេះស្វ័យប្រវត្តិ..."
      className="border p-2 rounded w-full"
    />
  );
}

5. Explanation (ការពន្យល់កូដ):

  • const inputRef = useRef(null) បង្កើត Reference Object មួយសម្រាប់ភ្ជាប់ទៅកាន់ស្លាក <input>។
  • [] (Empty Dependency Array) នៅចុង useEffect កំណត់ឱ្យកូដខាងក្នុងដំណើរការតែ 1 ដងគត់ពេលទំព័រផ្ទុកដំបូង។

6. Output (លទ្ធផល):

គ្រាន់តែបើកទំព័រភ្លាម Cursor សម្រាប់វាយអក្សរនឹងលោតចូលទៅក្នុងប្រអប់ Input ដោយស្វ័យប្រវត្តិ។

7. Practice (លំហាត់អនុវត្ត):

ចូរប្រើប្រាស់ useEffect ដើម្បីផ្លាស់ប្តូរ document.title របស់ Browser ទៅតាមចំនួនចុច count។

React.js Learning Book 14. React Router

14. React Router (ការប្តូរទំព័រក្នុង SPA)

1. Definition (តើវាជាអ្វី?):

React Router (react-router-dom) គឺជាបណ្ណាល័យស្តង់ដារសម្រាប់គ្រប់គ្រងការផ្លាស់ប្តូរទំព័រ (Routing) នៅក្នុងកម្មវិធី React ដោយមិនធ្វើឱ្យ Browser ផ្ទុកទំព័រឡើងវិញ (Zero Page Reload)។

2. Purpose (ធាតុផ្សំសំខាន់ៗរបស់ React Router):

  • <BrowserRouter> រុំព័ទ្ធកម្មវិធីទាំងមូលដើម្បីបើកមុខងារ Routing។
  • <Routes> និង <Route path="..." element={...} /> កំណត់ផ្លូវ URL និងទំព័រដែលត្រូវបង្ហាញ។
  • <Link to="..."> ប្រើជំនួសស្លាក <a href="..."> ដើម្បីផ្លាស់ទីរវាងទំព័រយ៉ាងរហ័ស។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលគេហទំព័រមានច្រើនទំព័រ ដូចជាទំព័រដើម (/), ទំព័រវគ្គសិក្សា (/courses) និងទំព័រអំពីយើង (/about)។

4. Syntax (ការដំឡើង និងកំណត់ផ្លូវទំព័រ):

// ដំឡើង៖ npm install react-router-dom
import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';

export default function App() {
  return (
    <BrowserRouter>
      <nav className="flex gap-4 p-4 bg-slate-900 text-white">
        <Link to="/">ទំព័រដើម</Link>
        <Link to="/about">អំពីយើង</Link>
      </nav>

      <Routes>
        <Route path="/" element={<h1>ទំព័រដើម (Home Page)</h1>} />
        <Route path="/about" element={<h1>អំពីយើង (About Page)</h1>} />
      </Routes>
    </BrowserRouter>
  );
}

5. Explanation (ការពន្យល់កូដ):

  • <Link to="/about"> ប្តូរអាសយដ្ឋាន URL ទៅជា /about ភ្លាមៗដោយមិនវិលកង់ Reload។
  • <Route path="/about" ... /> ចាប់យក URL នោះ ហើយបង្ហាញ Component ដែលបានកំណត់ក្នុង element។

6. Output (លទ្ធផល):

បង្ហាញរបារម៉ឺនុយខាងលើ ដែលអាចចុចប្តូរទៅមករវាង "ទំព័រដើម" និង "អំពីយើង" ក្នុងល្បឿនលឿនដូចកម្មវិធីទូរស័ព្ទ។

7. Practice (លំហាត់អនុវត្ត):

ចូរបង្កើតទំព័រចំនួន 3 (Home, Courses, Contact) រួចភ្ជាប់គ្នាដោយប្រើប្រាស់ React Router។

React.js Learning Book 15. API Integration

15. API Integration (ការទាញទិន្នន័យពី Server)

1. Definition (តើវាជាអ្វី?):

API Integration គឺជាការភ្ជាប់កម្មវិធី Frontend React ទៅកាន់ Backend Server ដើម្បីទាញយកទិន្នន័យពិតប្រាកដ (JSON Data) មកបង្ហាញនៅលើអេក្រង់តាមរយៈ fetch() ឬ async/await។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • បង្ហាញទិន្នន័យផលិតផល អត្ថបទព័ត៌មាន ឬអាកាសធាតុដែលធ្វើបច្ចុប្បន្នភាពផ្ទាល់ពីម៉ាស៊ីនមេ (Server)។
  • រួមបញ្ចូល useState (សម្រាប់ទុកទិន្នន័យ និងស្ថានភាព Loading) ជាមួយ useEffect (សម្រាប់ហៅ API ពេលបើកទំព័រ)។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅរាល់ពេលដែលកម្មវិធីត្រូវការអាន ឬបញ្ជូនទិន្នន័យទៅកាន់ RESTful API។

4. Syntax (ឧទាហរណ៍ការទាញទិន្នន័យ API ជាមួយ useEffect):

import { useState, useEffect } from 'react';

export default function ProductAPI() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch("https://jsonplaceholder.typicode.com/users")
      .then((res) => res.json())
      .then((data) => {
        setUsers(data);
        setLoading(false);
      });
  }, []);

  if (loading) return <p>កំពុងទាញយកទិន្នន័យ...</p>;

  return (
    <ul className="space-y-1">
      {users.map(({ id, name, email }) => (
        <li key={id}>{name} - {email}</li>
      ))}
    </ul>
  );
}

5. Explanation (ការពន្យល់កូដ):

  • fetch(...) ផ្ញើសំណើ HTTP GET ទៅកាន់ Server និងបម្លែងចម្លើយមកជា JSON តាមរយៈ res.json()។
  • setUsers(data) យកទិន្នន័យដែលទទួលបានទៅរក្សាទុកក្នុង State ដើម្បីគូសបង្ហាញលើ UI។

6. Output (លទ្ធផល):

បង្ហាញពាក្យ "កំពុងទាញយកទិន្នន័យ..." រយៈពេលខ្លី រួចបង្ហាញបញ្ជីឈ្មោះ និងអ៊ីមែលអ្នកប្រើប្រាស់ទាំង 10 នាក់ពី API។

7. Practice (លំហាត់អនុវត្ត):

ចូរទាញយកទិន្នន័យផលិតផលពី https://fakestoreapi.com/products មកបង្ហាញជា Grid Cards ដោយប្រើ Tailwind CSS។

React.js Learning Book 16. React Project Structure

16. React Project Structure

1. Definition (តើវាជាអ្វី?):

React Project Structure គឺជាការរៀបចំបែងចែក Folders និង Files នៅក្នុងថត src/ ឱ្យមានរបៀបរៀបរយតាមស្តង់ដារក្រុមហ៊ុន ដើម្បីងាយស្រួលធ្វើការងារជាក្រុម និងពង្រីក Project នៅថ្ងៃក្រោយ។

2. Purpose (ហេតុអ្វីត្រូវប្រើ?):

  • បែងចែកដាច់ពីគ្នារវាង Reusable UI (components/) និងទំព័រពេញលេញ (pages/)។
  • ងាយស្រួលស្វែងរក និងកែប្រែកូដនៅពេល Project មានទំហំធំ។

3. When to Use (តើប្រើនៅពេលណា?):

អនុវត្តនៅគ្រប់ Project React ជាក់ស្តែងទាំងអស់ចាប់ពីកម្រិតមធ្យមរហូតដល់កម្រិតអាជីព។

4. Syntax (រចនាសម្ព័ន្ធ Folder ស្តង់ដារក្នុង src/):

my-react-app/
├── public/                 # ឯកសារសាធារណៈ និង Favicon
├── src/
│   ├── assets/             # រូបភាព, រូបតំណាង (Images, SVGs)
│   ├── components/         # បំណែក UI ប្រើឡើងវិញបាន (Navbar.jsx, Card.jsx)
│   ├── pages/              # ទំព័រតាម Route (Home.jsx, Courses.jsx)
│   ├── data/               # ទិន្នន័យគំរូ (coursesData.js)
│   ├── App.jsx             # Component មេគ្រប់គ្រង Routes
│   ├── main.jsx            # ចំណុចចាប់ផ្តើមភ្ជាប់ទៅកាន់ index.html
│   └── index.css           # ឯកសារនាំចូល @import "tailwindcss";
└── package.json

5. Explanation (ការពន្យល់រចនាសម្ព័ន្ធ):

  • src/components/ ផ្ទុកបំណែកតូចៗដូចជា Button.jsx, ProductCard.jsx។
  • src/pages/ ផ្ទុកទំព័រធំៗដែលត្រូវភ្ជាប់ជាមួយ React Router។
  • src/main.jsx ប្រើ ReactDOM.createRoot() ដើម្បីបញ្ចូលកូដ React ទៅក្នុង <div id="root">។

6. Output (លទ្ធផល):

ទទួលបានគ្រោងឆ្អឹង Project ស្អាត មានសណ្តាប់ធ្នាប់ និងងាយស្រួល Deploy ឡើងលើប្រព័ន្ធ Vercel។

7. Practice (លំហាត់អនុវត្ត):

ចូររៀបចំបង្កើត Folders components, pages និង data នៅក្នុង Project របស់អ្នកតាមគំរូខាងលើ។

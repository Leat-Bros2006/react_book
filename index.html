React.js 01. Introduction to React.js

01. Introduction to React.js & Virtual DOM

1. Definition (តើវាជាអ្វី?):

React.js គឺជា JavaScript Library ដ៏ពេញនិយមបំផុតរបស់ក្រុមហ៊ុន Meta សម្រាប់បង្កើត User Interface (UI) លើ Web Application តាមបែប Single Page Application (SPA)។

2. Key Concepts & Roles (តួមេ និងមុខងារខ្វះមិនបាន):

  • Component-Based Architecture (តួមេ UI)៖ បំបែកអេក្រង់ទាំងមូលជាបំណែកតូចៗឯករាជ្យ ដែលអាចបង្កើតម្តង និងយកទៅប្រើឡើងវិញបានច្រើនដង។
  • Virtual DOM (មេបង្កើនល្បឿន)៖ ជាច្បាប់ចម្លងនៃ DOM លើ Memory។ ពេលទិន្នន័យប្តូរ React គណនាត្រង់ណាដែលប្តូរ រួចធ្វើបច្ចុប្បន្នភាពតែចំណុចនោះ បើគ្មានវាទេ ទំព័រនឹងត្រូវ Reload ពេញលេញយឺតយ៉ាវ។
  • Declarative Syntax៖ យើងគ្រាន់តែប្រាប់ React ថាតើ UI គួរមានទម្រង់បែបណា នោះ React នឹងចាត់ចែង Render ឱ្យដោយស្វ័យប្រវត្តិ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់បង្កើតគេហទំព័រដែលមានទិន្នន័យផ្លាស់ប្តូរញឹកញាប់ ដូចជា Dashboard, Social Media, E-commerce និង Web Apps ទំនើបៗ។

4. Syntax (ទម្រង់កូដ):

import React from 'react';

function App() {
  return (
    <div style={{ padding: '14px', background: '#E0F2FE', borderRadius: '6px' }}>
      <h1 style={{ color: '#0284C7', margin: '0 0 6px' }}>សួស្តី React.js!</h1>
      <p style={{ margin: 0, color: '#0F172A' }}>ស្វាគមន៍មកកាន់ការសិក្សា React.js ពីមូលដ្ឋាន!</p>
    </div>
  );
}

export default App;

5. Explanation (ការពន្យល់កូដ):

  • function App() គឺជា Functional Component មូលដ្ឋានដែលប្រគល់ធាតុ UI មកវិញ។
  • export default App; បញ្ជូន Component នេះចេញដើម្បីឱ្យឯកសារផ្សេងទៀតអាចទាញយកទៅប្រើបាន។

6. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173

សួស្តី React.js!

ស្វាគមន៍មកកាន់ការសិក្សា React.js ពីមូលដ្ឋាន!

7. Summary (សង្ខេបមេរៀន)៖ React គឺជា UI Library ដំណើរការតាមរយៈ Component និង Virtual DOM ជួយឱ្យ Web Application ដំណើរការលឿន មិនបាច់ Reload ទំព័រឡើយ។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 4
React.js 02. React Development Environment

02. React Development Environment (Vite Setup)

1. Definition (តើវាជាអ្វី?):

React Environment គឺជាការរៀបចំ Node.js, npm និង Build Tool ទំនើប (Vite) នៅលើកុំព្យូទ័រ ដើម្បីដំណើរការ និងអភិវឌ្ឍគម្រោង React ដោយរលូន។

2. Key Tools & Roles (តួមេ និងមុខងារខ្វះមិនបាន):

  • Node.js (មេដំណើរការ JavaScript ក្រៅ Browser)៖ ត្រូវការជាចាំបាច់ដើម្បីដំណើរការ npm និង Developer Tools។
  • npm (មេគ្រប់គ្រងកញ្ចប់បណ្ណាល័យ)៖ ប្រើសម្រាប់ទាញយក React និង Libraries ផ្សេងៗចូលម៉ាស៊ីន។
  • Vite (មេ Build Tool ជំនាន់ថ្មី)៖ លឿនជាង Create React App (CRA) រាប់សិបដង និងគាំទ្រ Hot Module Replacement (HMR) កែប្រែកូដភ្លាមឃើញលទ្ធផលភ្លាម។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើរាល់ពេលចាប់ផ្តើមបង្កើតគម្រោង React ថ្មីនៅលើម៉ាស៊ីនផ្ទាល់ខ្លួនតាម Terminal។

4. Syntax (ពាក្យបញ្ជាបង្កើត Project ក្នុង Terminal):

# ១. បង្កើតគម្រោងថ្មីជាមួយ Vite
npm create vite@latest my-react-app -- --template react

# ២. ចូលទៅកាន់ Folder គម្រោង និងដំឡើងបណ្ណាល័យ
cd my-react-app
npm install

# ៣. បើកដំណើរការ Development Server
npm run dev

5. Explanation (ការពន្យល់កូដ):

  • npm install បង្កើត Folder node_modules ដែលផ្ទុកកូដស្នូលរបស់ React ទាំងអស់។
  • npm run dev បើក Server សាកល្បងនៅអាសយដ្ឋាន http://localhost:5173។

6. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173

⚡ Vite + React

Development server is running at port 5173

7. Summary (សង្ខេបមេរៀន)៖ ការប្រើ Vite រួមជាមួយ Node.js គឺជាមធ្យោបាយបង្កើតគម្រោង React ស្តង់ដារលឿនបំផុត និងមានប្រសិទ្ធភាពខ្ពស់នាពេលបច្ចុប្បន្ន។

React.js 03. JSX Fundamentals

03. JSX Fundamentals & Fragment

1. Definition (តើវាជាអ្វី?):

JSX (JavaScript XML) គឺជាទម្រង់ពង្រីករបស់ JavaScript ដែលអនុញ្ញាតឱ្យយើងសរសេរទម្រង់កូដស្រដៀង HTML នៅខាងក្នុង JavaScript យ៉ាងងាយស្រួល។

2. Key Rules & Roles (ច្បាប់តឹងរ៉ឹងខ្វះមិនបានក្នុង JSX):

  • Single Root Element (មេរុំព័ទ្ធ)៖ Component ត្រូវតែប្រគល់ធាតុ Root តែមួយគត់។ បើមិនចង់បង្កើត <div> លើសក្នុង DOM ត្រូវប្រើ Fragment (<>...</>)។
  • Close All Tags (មេបិទស្លាក)៖ គ្រប់ស្លាកទាំងអស់ត្រូវតែបិទជានិច្ច រួមទាំងស្លាកទោល ដូចជា <img />, <input /> និង <br />។
  • Expressions in JSX ({ })៖ រាល់ការហៅអថេរ គណនាលេខ ឬលក្ខខណ្ឌ ត្រូវដាក់ក្នុងសញ្ញាខ្នងក្រពើ { }។
  • Attributes៖ ប្រើ className ជំនួស class និងប្រើ htmlFor ជំនួស for។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើរាល់ពេលសរសេរកូដរៀបចំទម្រង់ UI ក្នុង React Component។

4. Syntax (ទម្រង់កូដ):

function CourseInfo() {
  const title = "React.js ពីមូលដ្ឋានដល់ការអនុវត្ត";
  const fee = 45;

  return (
    <>
      <h3 style={{ color: '#0284C7', margin: '0 0 4px' }}>វគ្គ៖ {title}</h3>
      <p style={{ margin: '0 0 8px' }}>តម្លៃ៖ ${fee} (ចុះសល់ត្រឹម ${fee - 10})</p>
      <input type="text" placeholder="បញ្ចូលឈ្មោះសិស្ស..." />
    </>
  );
}

export default CourseInfo;

5. Explanation (ការពន្យល់កូដ):

  • <>...</> ជា React Fragment ជួយរុំព័ទ្ធធាតុកូនដោយមិនបង្កើត HTML Tag ឥតប្រយោជន៍លើ DOM។
  • {fee - 10} បង្កប់ការគណនា JavaScript ដោយផ្ទាល់ក្នុង JSX។

6. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173

វគ្គ៖ React.js ពីមូលដ្ឋានដល់ការអនុវត្ត

តម្លៃ៖ $45 (ចុះសល់ត្រឹម $35)

7. Summary (សង្ខេបមេរៀន)៖ JSX ត្រូវតែបិទស្លាកគ្រប់កន្លែង មាន Parent តែមួយ (ឬប្រើ Fragment <>...</>) និងប្រើ { } បង្ហាញតម្លៃអថេរ។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 6
React.js 04. Destructuring (ES6+)

04. Array & Object Destructuring (ES6+)

1. Definition (តើវាជាអ្វី?):

Destructuring គឺជា Syntax ក្នុង ES6+ សម្រាប់ទាញយកតម្លៃចេញពី Array ឬ Object មកផ្ទុកក្នុង Variables ដាច់ដោយឡែកយ៉ាងរហ័ស និងមានរបៀប។

2. Key Forms & Roles (តួនាទីខ្វះមិនបានក្នុង React):

  • Array Destructuring ([a, b] = arr)៖ ទាញយកធាតុតាមលំដាប់លំដោយ Index។ នេះជាគ្រឹះតែមួយគត់ដែល React ប្រើប្រាស់ក្នុងការបង្កើត State តាមរយៈ const [data, setData] = useState()។
  • Object Destructuring ({ name } = obj)៖ ទាញយកទិន្នន័យតាមឈ្មោះ Key ផ្ទាល់ ប្រើសម្រាប់ទទួល Props ក្នុង Component កុំឱ្យសរសេរ props.name ផ្ទួនៗ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើរាល់ពេលបង្កើត State ដោយ useState និងរាល់ពេលទទួល Props ក្នុង Functional Components។

4. Syntax (ទម្រង់កូដ):

// ១. Array Destructuring តាមលំដាប់លំដោយ Index
const tools = ["React", "Vite"];
const [primaryTool, buildTool] = tools;

// ២. Object Destructuring តាមឈ្មោះ Property Key
const teacher = { fullName: "លាត ប្រុស", skill: "React.js" };

function Profile() {
  const { fullName, skill } = teacher;
  return (
    <p>លោកគ្រូ <strong>{fullName}</strong> បង្រៀន {skill} ជាមួយ {primaryTool} &amp; {buildTool}</p>
  );
}

export default Profile;

5. Explanation (ការពន្យល់កូដ):

  • const [primaryTool, buildTool] ចាប់យកតម្លៃ "React" និង "Vite" តាមលំដាប់។
  • const { fullName, skill } ចាប់យកតម្លៃតាមឈ្មោះ Key ដោយមិនខ្វល់ពីលំដាប់មុនក្រោយឡើយ។

6. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173

លោកគ្រូ លាត ប្រុស បង្រៀន React.js ជាមួយ React & Vite

7. Summary (សង្ខេបមេរៀន)៖ Destructuring ធ្វើឱ្យកូដខ្លីស្អាត ដោយ Array Destructuring ប្រើសម្រាប់ Hooks (useState) និង Object Destructuring ប្រើសម្រាប់ Props។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 7
React.js 05. React Components

05. React Components (Export & Import)

1. Definition (តើវាជាអ្វី?):

React Component គឺជាអនុគមន៍ JavaScript ឯករាជ្យ (ឈ្មោះត្រូវផ្តើមដោយអក្សរធំ PascalCase) ដែលប្រគល់មកវិញនូវ JSX និងអាចភ្ជាប់គ្នារវាង File តាមរយៈ Export និង Import។

2. Key Types & Roles (តួនាទី Export ទាំង ២ ប្រភេទ):

  • Default Export (export default App;)៖ ក្នុងមួយ File មានបានតែមួយគត់ ពេល Import ចូល មិនបាច់ប្រើសញ្ញាខ្នងក្រពើ { } ឡើយ។
  • Named Export (export function Btn())៖ ក្នុងមួយ File អាចមានច្រើន ពេល Import ចូល ត្រូវតែដាក់ក្នុងសញ្ញា { Btn } ជាដាច់ខាត។
  • PascalCase Convention៖ ឈ្មោះ Component ត្រូវសរសេរអក្សរធំនៅខាងដើមជានិច្ច (ដូចជា Navbar មិនមែន navbar ទេ) ដើម្បីកុំឱ្យច្រឡំជាមួយ HTML Tags ធម្មតា។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់បំបែក UI នៃគេហទំព័រឱ្យទៅជាឯកសារដាច់ដោយឡែកៗពីគ្នា ងាយស្រួលថែទាំ។

4. Syntax (ទម្រង់កូដ):

// ១. ឯកសារ src/components/Buttons.jsx (Named Export)
export function DangerBtn() {
  return <button style={{ background: '#DC2626', color: '#fff', border: 0, padding: '6px 12px', borderRadius: '4px' }}>លុប</button>;
}

// ២. ឯកសារ src/App.jsx (Default Export)
import { DangerBtn } from './components/Buttons';

function App() {
  return (
    <div style={{ display: 'flex', gap: '10px', alignItems: 'center' }}>
      <span>តើអ្នកចង់លុបទិន្នន័យនេះមែនទេ?</span>
      <DangerBtn />
    </div>
  );
}

export default App;

5. Explanation (ការពន្យល់កូដ):

  • DangerBtn ត្រូវហៅចូលជាមួយ { DangerBtn } ព្រោះវាជា Named Export។
  • export default App; នៅបាតក្រោមឯកសារ អនុញ្ញាតឱ្យ main.jsx ទាញយកទៅ Render។

6. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173
តើអ្នកចង់លុបទិន្នន័យនេះមែនទេ?
7. Summary (សង្ខេបមេរៀន)៖ Components ត្រូវសរសេរអក្សរធំនៅដើម PascalCase ហើយការបែងចែកឯកសារត្រូវប្រើ export default សម្រាប់តួមេ និង export សម្រាប់តួកូន។

React.js 06. Props

06. Props (Component Communication)

1. Definition (តើវាជាអ្វី?):

Props (Properties) គឺជាយន្តការសម្រាប់បញ្ជូនទិន្នន័យពី Component មេ (Parent) ចុះទៅកាន់ Component កូន (Child) ក្នុងទិសដៅតែមួយ (Unidirectional Data Flow)។

2. Key Rules & Roles (ច្បាប់តឹងរ៉ឹងនៃ Props):

  • Read-Only (ហាមកែប្រែតម្លៃ)៖ ធាតុកូនមានសិទ្ធិត្រឹមតែអានយកទិន្នន័យ Props មកបង្ហាញប៉ុណ្ណោះ ហាមកែប្រែតម្លៃ Props ដោយផ្ទាល់ជាដាច់ខាត។
  • Pass via Attributes (បញ្ជូនដូច Attribute)៖ បញ្ជូនទិន្នន័យតាមឈ្មោះ Property ដូចជា title="React" ឬ isOnline={true}។
  • Receive via Destructuring (ទទួលតាម {})៖ បំបែក Props ក្នុង Parameter នៃអនុគមន៍កូនភ្លាមៗ ដើម្បីកូដខ្លី និងងាយស្រួលមើល។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលដែលយើងចង់ឱ្យ Component តែមួយ (ដូចជា UserCard ឬ Button) អាចបង្ហាញព័ត៌មាន និងរូបរាងខុសៗគ្នាតាមការបញ្ជូនទិន្នន័យពីខាងក្រៅ។

4. Syntax (ទម្រង់កូដ):

// Component កូន (ទទួល Props តាមរយៈ Destructuring)
function UserBadge({ name, role, isOnline }) {
  return (
    <div style={{ border: '1px solid #E2E8F0', padding: '8px 12px', borderRadius: '6px', background: '#F8FAFC' }}>
      <strong style={{ color: '#0284C7' }}>{name}</strong> - {role} | ស្ថានភាព៖ {isOnline ? "🟢 Online" : "⚪ Offline"}
    </div>
  );
}

// Component មេ (បញ្ជូន Props)
function App() {
  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '8px' }}>
      <UserBadge name="លាត ប្រុស" role="Instructor" isOnline={true} />
      <UserBadge name="សុខា" role="Student" isOnline={false} />
    </div>
  );
}

export default App;

5. Explanation (ការពន្យល់កូដ):

  • { name, role, isOnline } ចាប់យក Properties ពី Object Props ដោយផ្ទាល់។
  • តម្លៃជា Boolean ឬ Number ត្រូវដាក់ក្នុងសញ្ញា { } ដូចជា isOnline={true}។

6. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173
លាត ប្រុស - Instructor | ស្ថានភាព៖ 🟢 Online
សុខា - Student | ស្ថានភាព៖ ⚪ Offline
7. Summary (សង្ខេបមេរៀន)៖ Props បញ្ជូនទិន្នន័យពីមេទៅកូនក្នុងទម្រង់ Read-Only ដើម្បីឱ្យ Component អាច Re-use បង្ហាញទិន្នន័យច្រើនបែបបានយ៉ាងមានប្រសិទ្ធភាព។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 9
React.js 07. State & useState Hook

07. State and useState Hook

1. Definition (តើវាជាអ្វី?):

State គឺជាអង្គចងចាំផ្ទៃក្នុងរបស់ Component សម្រាប់ផ្ទុកទិន្នន័យដែលអាចផ្លាស់ប្តូរបាន។ នៅពេល State ប្តូរតម្លៃ វានឹងបញ្ជាឱ្យ React ធ្វើការ Re-render UI ឡើងវិញស្វ័យប្រវត្តិ។

2. Key Parts & Roles (តួមេនៃ useState):

  • Variable (count)៖ តម្លៃបច្ចុប្បន្ននៃ State សម្រាប់យកទៅបង្ហាញលើ UI។
  • Setter Function (setCount - ខ្វះមិនបាន)៖ អនុគមន៍តែមួយគត់ដែលប្រើសម្រាប់ផ្លាស់ប្តូរតម្លៃ State និងបញ្ជាឱ្យ Re-render (ហាមកែតម្លៃ count = count + 1 ដោយផ្ទាល់)។
  • Initial State (useState(0))៖ តម្លៃចាប់ផ្តើមដំបូងបង្អស់ពេល Component បង្ហាញខ្លួន។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់គ្រប់ទិន្នន័យដែលមានអន្តរកម្មដូចជា៖ ចំនួនចុច Counter, ការបើក/បិទ Dropdown, និងទិន្នន័យក្នុងប្រអប់ Form។

4. Syntax (ទម្រង់កូដ):

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div style={{ padding: '10px' }}>
      <h3 style={{ color: '#0284C7', margin: '0 0 6px' }}>ចំនួនចុច៖ {count}</h3>
      <button onClick={() => setCount(count + 1)} style={{ padding: '5px 12px', background: '#0284C7', color: '#fff', border: 0, borderRadius: '4px', marginRight: '6px' }}>បន្ថែម +1</button>
      <button onClick={() => setCount(0)} style={{ padding: '5px 12px', background: '#64748B', color: '#fff', border: 0, borderRadius: '4px' }}>កំណត់ឡើងវិញ</button>
    </div>
  );
}

export default Counter;

5. Explanation (ការពន្យល់កូដ):

  • const [count, setCount] = useState(0) ប្រើ Array Destructuring បង្កើត State តម្លៃ 0។
  • setCount(count + 1) ផ្លាស់ប្តូរតម្លៃ និងបញ្ជាឱ្យ React គូស UI ថ្មីភ្លាមៗ។

6. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173

ចំនួនចុច៖ 1

7. Summary (សង្ខេបមេរៀន)៖ State គ្រប់គ្រងទិន្នន័យមានចលនា ហើយត្រូវផ្លាស់ប្តូរតម្លៃតាមរយៈ Setter Function ជានិច្ចដើម្បីឱ្យ UI ធ្វើបច្ចុប្បន្នភាពតាម។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 10
React.js 08. Event Handling

08. Event Handling (Synthetic Events)

1. Definition (តើវាជាអ្វី?):

Event Handling គឺជាការឆ្លើយតបទៅនឹងសកម្មភាពរបស់អ្នកប្រើប្រាស់ (ដូចជាការចុច Click ឬការវាយអត្ថបទ) ដោយប្រើប្រាស់ Synthetic Events របស់ React តាមទម្រង់ camelCase។

2. Key Rules & Roles (ភាពខុសគ្នារវាង HTML និង React Events):

  • camelCase Convention (សរសេរអក្សរផ្សំធំ)៖ ប្រើ onClick ជំនួស onclick និង onChange ជំនួស onchange។
  • Pass as Function (បញ្ជូនជាអនុគមន៍)៖ បញ្ជូនជា Function Reference onClick={handleClick} (ហាមដាក់វង់ក្រចក onClick={handleClick()} ព្រោះវានឹងដំណើរការភ្លាមៗពេលទំព័រមិនទាន់ទាំងចុច)។
  • Event Object (e.target.value)៖ ចាប់យកតម្លៃដែលអ្នកប្រើកំពុងវាយចេញពីប្រអប់ Input ភ្លាមៗ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើលើគ្រប់ប៊ូតុង ប្រអប់បញ្ចូលអត្ថបទ និងការចុច Submit Form លើគេហទំព័រ។

4. Syntax (ទម្រង់កូដ):

import { useState } from 'react';

function InputLogger() {
  const [text, setText] = useState("");

  return (
    <div>
      <input 
        type="text" 
        placeholder="វាយអត្ថបទទីនេះ..." 
        onChange={(e) => setText(e.target.value)} 
      />
      <p>អក្សរដែលអ្នកវាយ៖ <strong style={{ color: '#0284C7' }}>{text}</strong></p>
    </div>
  );
}

export default InputLogger;

5. Explanation (ការពន្យល់កូដ):

  • onChange={(e) => setText(e.target.value)} ចាប់យករាល់តួអក្សរដែលវាយបញ្ចូលទៅផ្ទុកក្នុង State text ភ្លាមៗ។

6. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173

អក្សរដែលអ្នកវាយ៖ សួស្តីលោកគ្រូ

7. Summary (សង្ខេបមេរៀន)៖ Events ក្នុង React សរសេរជា camelCase និងបញ្ជូនជា Function Callback ដោយប្រើ e.target.value សម្រាប់ចាប់យកតម្លៃពីប្រអប់ Input។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 11
React.js 09. Conditional Rendering

09. Conditional Rendering

1. Definition (តើវាជាអ្វី?):

Conditional Rendering គឺជាការសម្រេចចិត្តបង្ហាញ ឬលាក់ធាតុ UI ណាមួយដោយផ្អែកលើលក្ខខណ្ឌពិត (true) ឬមិនពិត (false) នៃ State ឬ Props។

2. Key Operators & Roles (វិធីសាស្ត្រស្នូលទាំង ២):

  • Ternary Operator (condition ? A : B)៖ ប្រើពេលមានជម្រើស ២ ផ្ទុយគ្នា (ឧ. បើ Login ហើយ បង្ហាញប៊ូតុង "Logout" បើមិនទាន់ Login បង្ហាញ "Login")។
  • Logical AND Operator (condition && A)៖ ប្រើពេលចង់បង្ហាញធាតុ A លុះត្រាតែលក្ខខណ្ឌពិត (បើមិនពិត គឺមិនបង្ហាញអ្វីទាំងអស់)។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់ផ្ទាំងផ្ទៀងផ្ទាត់សិទ្ធិ User, បង្ហាញសញ្ញា "កំពុងដំណើរការ (Loading...)" និងការបង្ហាញសារជូនដំណឹងពេល Error។

4. Syntax (ទម្រង់កូដ):

import { useState } from 'react';

function AuthStatus() {
  const [isLoggedIn, setIsLoggedIn] = useState(true);

  return (
    <div>
      {isLoggedIn ? (
        <button onClick={() => setIsLoggedIn(false)} style={{ background: '#DC2626', color: '#fff', border: 0, padding: '5px 12px', borderRadius: '4px' }}>ចាកចេញ (Logout)</button>
      ) : (
        <button onClick={() => setIsLoggedIn(true)} style={{ background: '#0284C7', color: '#fff', border: 0, padding: '5px 12px', borderRadius: '4px' }}>ចូលគណនី (Login)</button>
      )}
      {isLoggedIn && <p style={{ color: '#16A34A', margin: '6px 0 0' }}>✓ អ្នកកំពុងស្ថិតក្នុងគណនី</p>}
    </div>
  );
}

export default AuthStatus;

5. Explanation (ការពន្យល់កូដ):

10. Lists and Keys (Array Mapping)

1. Definition (តើវាជាអ្វី?):

2. Key Parts & Roles (តួនាទីខ្វះមិនបាននៃ Key):

  • Array.map() (មេបំប្លែងទិន្នន័យ)៖ ដើរឆ្លងកាត់ធាតុនីមួយៗក្នុង Array ហើយប្រគល់មកវិញនូវស្លាក JSX ស្វ័យប្រវត្តិ។

3. When to Use (តើប្រើនៅពេលណា?):

4. Syntax (ទម្រង់កូដ):

11. Forms Handling (Controlled Components)

1. Definition (តើវាជាអ្វី?):

Controlled Component គឺជាទម្រង់គ្រប់គ្រងប្រអប់ Form នៅក្នុង React ដែលតម្លៃរបស់ Input (value) ត្រូវបានភ្ជាប់ និងគ្រប់គ្រងទាំងស្រុងដោយ React State។

2. Key Roles & Functions (តួនាទីខ្វះមិនបាន):

  • value={state} (មេភ្ជាប់ទិន្នន័យ)៖ បង្ខំឱ្យ Input បង្ហាញតម្លៃតាម State ជានិច្ច (Single Source of Truth)។
  • onChange (មេធ្វើបច្ចុប្បន្នភាព)៖ ធ្វើបច្ចុប្បន្នភាព State រាល់ពេលអ្នកប្រើប្រាស់វាយអក្សរចូល។
  • e.preventDefault() (មេទប់ស្កាត់ - ខ្វះមិនបាន)៖ ទប់ស្កាត់មិនឱ្យ Browser ធ្វើការ Refresh ទំព័រឡើងវិញនៅពេលចុច Submit Form។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់គ្រប់ទម្រង់ Login, ចុះឈ្មោះ និងប្រអប់ស្វែងរក Search ទាំងអស់ក្នុង React។

4. Syntax (ទម្រង់កូដ):

import { useState } from 'react';

function LoginForm() {
  const [email, setEmail] = useState("");

  const handleSubmit = (e) => {
    e.preventDefault(); /* ការពារកុំឱ្យ Refresh ទំព័រ */
    alert(`បានបញ្ជូនអ៊ីមែល៖ ${email}`);
    setEmail(""); /* សម្អាតប្រអប់ក្រោយ Submit */
  };

  return (
    <form onSubmit={handleSubmit} style={{ display: 'flex', gap: '8px' }}>
      <input type="email" value={email} onChange={(e) => setEmail(e.target.value)} placeholder="you@email.com" required />
      <button type="submit" style={{ background: '#0284C7', color: '#fff', border: 0, padding: '5px 12px', borderRadius: '4px' }}>បញ្ជូន</button>
    </form>
  );
}

export default LoginForm;

5. Explanation (ការពន្យល់កូដ):

  • value={email} និង onChange ដំណើរការស្របគ្នាបង្កើតបានជា Controlled Component ពេញលេញ។

6. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173
7. Summary (សង្ខេបមេរៀន)៖ ការគ្រប់គ្រង Form ត្រូវភ្ជាប់ value ទៅ State និងប្រើ e.preventDefault() ដើម្បីទប់ស្កាត់ការ Refresh ទំព័រឡើងវិញ។

12. LocalStorage & Data Persistence

1. Definition (តើវាជាអ្វី?):

LocalStorage គឺជា Web Storage API របស់ Browser សម្រាប់រក្សាទុកទិន្នន័យជាអចិន្ត្រៃយ៍លើម៉ាស៊ីនអ្នកប្រើប្រាស់ ទោះបីជាបិទ ឬ Refresh Browser ក៏មិនបាត់បង់ទិន្នន័យដែរ។

2. Key Methods & Roles (តួមេទាំង ២ ក្នុងការគ្រប់គ្រងទិន្នន័យ):

  • JSON.stringify() (មេបម្លែងជា String)៖ LocalStorage ស្គាល់តែ String ដូច្នេះរាល់ Object ឬ Array ត្រូវបម្លែងជា String មុនរក្សាទុកតាម localStorage.setItem()។
  • JSON.parse() (មេបម្លែងជា Object វិញ)៖ ពេលទាញទិន្នន័យតាម localStorage.getItem() ត្រូវបម្លែងពី String មកជា Object ឬ Array វិញដើម្បីយកមកប្រើក្នុង React State។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើសម្រាប់រក្សាទុកទិន្នន័យកន្ត្រកទំនិញ (Cart), បញ្ជីការងារ Todo List និងការកំណត់ Theme (Dark/Light Mode)។

4. Syntax (ទម្រង់កូដ):

import { useState, useEffect } from 'react';

function NameSaver() {
  const [name, setName] = useState(() => {
    return localStorage.getItem("app_user") || "";
  });

  useEffect(() => {
    localStorage.setItem("app_user", name);
  }, [name]);

  return (
    <input 
      value={name} 
      onChange={(e) => setName(e.target.value)} 
      placeholder="វាយឈ្មោះរក្សាទុក..." 
    />
  );
}

export default NameSaver;

5. Explanation (ការពន្យល់កូដ):

  • useState(() => ...) ទាញយកឈ្មោះពី LocalStorage មកធ្វើជាតម្លៃដើមពេលបើកទំព័រដំបូង។
  • useEffect ធ្វើបច្ចុប្បន្នភាពទិន្នន័យក្នុង Storage ស្វ័យប្រវត្តិតាម [name]។

6. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173
💾 រក្សាទុកក្នុង LocalStorage រួចរាល់ (Refresh មិនបាត់)
7. Summary (សង្ខេបមេរៀន)៖ LocalStorage រក្សាទុកទិន្នន័យអចិន្ត្រៃយ៍លើ Client ដោយប្រើប្រាស់គូ JSON.stringify() សម្រាប់រក្សាទុក និង JSON.parse() សម្រាប់ទាញយកមកវិញ។

React.js 13. React Hooks

13. React Hooks (useEffect & useRef)

1. Definition (តើវាជាអ្វី?):

React Hooks គឺជាអនុគមន៍ពិសេសសម្រាប់គ្រប់គ្រង Lifecycle និង DOM ដោយ useEffect គ្រប់គ្រង Side Effects និង useRef ប្រើសម្រាប់ចាប់យកធាតុ DOM ដោយផ្ទាល់។

2. Key Roles & Differences (តួនាទីខ្វះមិនបាន):

  • useEffect (មេគ្រប់គ្រង Side Effects)៖ ដំណើរការកូដក្រោយពេល Render រួច។ បើដាក់ Dependency [] ទំនេរ វានឹងដំណើរការតែម្តងគត់ (Component Mount) ដូចជាការ Fetch Data។
  • useRef (មេចាប់ DOM ដោយមិន Re-render)៖ ភ្ជាប់ទៅធាតុ HTML ផ្ទាល់តាម ref={myRef} ដើម្បីបញ្ជា .focus() ដោយមិនបង្កឱ្យ Component ត្រូវគូសឡើងវិញឡើយ។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើ useEffect ពេលទាញទិន្នន័យពី API និងប្រើ useRef ពេលចង់ឱ្យ Cursor លោតចូលប្រអប់ Input ស្វ័យប្រវត្តិ។

4. Syntax (ទម្រង់កូដ):

import { useEffect, useRef } from 'react';

function AutoFocusInput() {
  const inputRef = useRef(null);

  useEffect(() => {
    inputRef.current.focus(); /* Cursor លោតចូល Input ភ្លាមពេលបើកទំព័រ */
  }, []);

  return (
    <input ref={inputRef} placeholder="វាយទីនេះភ្លាមៗ..." />
  );
}

export default AutoFocusInput;

5. Explanation (ការពន្យល់កូដ):

  • ref={inputRef} ភ្ជាប់អថេរ Reference ទៅនឹង DOM Input ជាក់ស្តែង។
  • [] ធានាថាកូដ Focus ដំណើរការតែមួយដងគត់ពេលបើកទំព័រដំបូង។

6. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173
✨ Cursor លោតចូលប្រអប់ស្វ័យប្រវត្តិតាមរយៈ useRef + useEffect
7. Summary (សង្ខេបមេរៀន)៖ useEffect ដោះស្រាយ Side Effects តាមរយៈ Dependency Array រីឯ useRef ចាប់យក DOM ផ្ទាល់ដោយមិនធ្វើឱ្យ Re-render។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 16
React.js 14. React Router

14. React Router (Client-Side Navigation)

1. Definition (តើវាជាអ្វី?):

React Router (react-router-dom) គឺជាបណ្ណាល័យសម្រាប់គ្រប់គ្រងការផ្លាស់ប្តូរទំព័រលើ Client-Side ដោយមិនបាច់ Reload ទំព័រឡើងវិញឡើយ។

2. Key Components & Roles (តួមេខ្វះមិនបានក្នុង Routing):

  • <BrowserRouter> (មេធំនៃ Routing)៖ រុំព័ទ្ធ Component ទាំងអស់ដើម្បីបើកដំណើរការ Navigation។
  • <Routes> & <Route> (មេផ្គូផ្គងផ្លូវ)៖ ពិនិត្យមើល URL និងបង្ហាញ Component ដែលត្រូវនឹង Path នោះ។
  • <Link to="..."> (មេប្តូរទំព័រ - ខ្វះមិនបាន)៖ ប្រើជំនួសស្លាក <a> ធម្មតា ដើម្បីប្តូរទំព័រលឿនដូចផ្លេកបន្ទោរដោយមិនវិលកង់ Reload។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើនៅពេលដែលគេហទំព័រមានច្រើនទំព័រដូចជា៖ ទំព័រដើម (/), ទំព័រអំពីយើង (/about) និងទំព័រទំនាក់ទំនង (/contact)។

4. Syntax (ទម្រង់កូដ):

import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';

function App() {
  return (
    <BrowserRouter>
      <nav style={{ display: 'flex', gap: '12px', borderBottom: '1px solid #E2E8F0', paddingBottom: '6px' }}>
        <Link to="/" style={{ color: '#0284C7', textDecoration: 'none' }}>ទំព័រដើម</Link>
        <Link to="/about" style={{ color: '#0284C7', textDecoration: 'none' }}>អំពីយើង</Link>
      </nav>
      <Routes>

React.js 15. API Integration

15. API Integration (Async/Await & Try-Catch-Finally)

1. Definition (តើវាជាអ្វី?):

API Integration គឺជាការតភ្ជាប់កម្មវិធី React ទៅកាន់ Backend Server ដើម្បីទាញយកទិន្នន័យ (JSON) តាមរយៈអនុគមន៍ async/await រួមជាមួយប្លុក try-catch-finally សម្រាប់គ្រប់គ្រងដំណើរការ និង Error ឱ្យមានសុវត្ថិភាពខ្ពស់។

2. Key Roles & States (តួនាទីខ្វះមិនបានក្នុង try-catch-finally):

  • try block (មេដំណើរការទាញទិន្នន័យ)៖ ផ្ទុកកូដ Fetch ទិន្នន័យជាមួយ await fetch() និងបម្លែងជា JSON តាមរយៈ await res.json()។
  • catch block (មេចាប់ Error)៖ ដំណើរការស្វ័យប្រវត្តិតែនៅពេលមានបញ្ហាដាច់អ៊ីនធឺណិត ឬ Server ខូច ដើម្បីកុំឱ្យកម្មវិធីគាំង (Crash)។
  • finally block (មេបញ្ចប់កិច្ចការ - ខ្វះមិនបាន)៖ ដំណើរការជាចុងក្រោយជានិច្ច ទោះបីជោគជ័យ ឬបរាជ័យក៏ដោយ ស័ក្តិសមបំផុតសម្រាប់បិទ Loading តាមរយៈ setLoading(false)។
  • useEffect with [] (មេទាញពេលបើកទំព័រ)៖ ដំណើរការទាញយកទិន្នន័យតែម្តងគត់នៅពេល Component បង្ហាញខ្លួនដំបូង។

3. When to Use (តើប្រើនៅពេលណា?):

ប្រើរាល់ពេលដែលកម្មវិធីត្រូវការទាញទិន្នន័យជាក់ស្តែងពី Database ដូចជាបញ្ជីអ្នកប្រើប្រាស់ បញ្ជីផលិតផល ឬទិន្នន័យអត្ថបទពី RESTful API។

4. Syntax (ទម្រង់កូដ):

import { useState, useEffect } from 'react';

function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchUsers = async () => {
      try {
        const res = await fetch("https://jsonplaceholder.typicode.com/users?_limit=2");
        const data = await res.json();
        setUsers(data);
      } catch (error) {
        console.error("មានបញ្ហាក្នុងការទាញទិន្នន័យ៖", error);
      } finally {
        setLoading(false); /* បិទ Loading ជានិច្ចទោះបីជោគជ័យ ឬខុស */
      }
    };

    fetchUsers();
  }, []);

  if (loading) return <p>កំពុងទាញទិន្នន័យ...</p>;

  return (
    <ul>
      {users.map(({ id, name }) => (
        <li key={id}>{name}</li>
      ))}
    </ul>
  );
}

export default UserList;

5. Explanation (ការពន្យល់កូដ):

  • មិនអាចដាក់ពាក្យ async ផ្ទាល់លើ useEffect(async () => ...) បានទេ ដូច្នេះត្រូវបង្កើតអនុគមន៍ const fetchUsers = async () => {} នៅខាងក្នុងរួចហៅដំណើរការវា។
  • finally ធានាថា setLoading(false) ដំណើរការជានិច្ច ជួយការពារកុំឱ្យទំព័រវិលកង់ Loading រហូតពេលដាច់អ៊ីនធឺណិត។

6. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173

7. Summary (សង្ខេបមេរៀន)៖ ការប្រើប្រាស់ async/await ជាមួយ try-catch-finally ធ្វើឱ្យកូដទាញទិន្នន័យស្អាត ងាយអាន និងធានាថា loading ត្រូវបានបិទជានិច្ចក្នុងប្លុក finally។

17. Practical Project: Task Manager (Pure React & CSS)

1. Project Overview (សេចក្តីពិពណ៌នាគម្រោង):

បង្កើតកម្មវិធីគ្រប់គ្រងកិច្ចការសិក្សាពេញលេញ ដោយប្រើប្រាស់ React សុទ្ធសាធ រួមមាន useState, useEffect, LocalStorage និងការរចនាដោយ CSS ស្តង់ដារ (មិនប្រើ Tailwind ឡើយ)។

2. Key Features (មុខងារស្នូល):

  • បន្ថែម និងលុបកិច្ចការសិក្សាបានភ្លាមៗដោយគ្មានការ Reload ទំព័រ។
  • រក្សាទុកទិន្នន័យអចិន្ត្រៃយ៍ក្នុង LocalStorage (Refresh ទំព័រមិនបាត់ឡើយ)។

4. Complete Code (កូដពេញលេញសម្រាប់អនុវត្ត):

import { useState, useEffect } from 'react';

function TaskManager() {
  const [tasks, setTasks] = useState(() => {
    const saved = localStorage.getItem("tasks_db");
    return saved ? JSON.parse(saved) : [];
  });
  const [text, setText] = useState("");

  useEffect(() => {
    localStorage.setItem("tasks_db", JSON.stringify(tasks));
  }, [tasks]);

  const addTask = (e) => {
    e.preventDefault();
    if (!text.trim()) return;
    setTasks([...tasks, { id: Date.now(), title: text }]);
    setText("");
  };

  const deleteTask = (id) => setTasks(tasks.filter((item) => item.id !== id));

  return (
    <div style={{ maxWidth: '380px', margin: '0 auto', padding: '12px', border: '1px solid #CBD5E1', borderRadius: '6px' }}>
      <h3 style={{ color: '#0284C7', margin: '0 0 8px' }}>កម្មវិធីគ្រប់គ្រងកិច្ចការ</h3>
      <form onSubmit={addTask} style={{ display: 'flex', gap: '6px', marginBottom: '8px' }}>
        <input value={text} onChange={(e) => setText(e.target.value)} placeholder="កិច្ចការថ្មី..." style={{ flex: 1, padding: '4px 8px' }} />
        <button style={{ background: '#0284C7', color: '#fff', border: 0, padding: '4px 10px', borderRadius: '4px' }}>បន្ថែម</button>
      </form>
      <ul style={{ listStyle: 'none', padding: 0, margin: 0 }}>
        {tasks.map(({ id, title }) => (
          <li key={id} style={{ display: 'flex', justifyContent: 'space-between', padding: '4px 0', borderBottom: '1px dashed #E2E8F0' }}>
            <span>{title}</span>
            <button onClick={() => deleteTask(id)} style={{ background: '#DC2626', color: '#fff', border: 0, padding: '2px 6px', borderRadius: '3px', fontSize: '0.75rem' }}>លុប</button>
          </li>
        ))}
      </ul>
    </div>
  );
}

export default TaskManager;

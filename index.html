React.js 01. Introduction to React.js

01. Introduction to React.js & Virtual DOM

1. Definition (និយមន័យ):

React.js គឺជា JavaScript Library ដ៏ពេញនិយមមួយ ដែលបង្កើតឡើងដោយក្រុមហ៊ុន Facebook (Meta) សម្រាប់អភិវឌ្ឍផ្ទៃខាងមុខនៃគេហទំព័រ (UI) តាមបែប Single Page Application (SPA)។

2. មូលហេតុដែលគួរប្រើប្រាស់ React.js៖

  • Component-Based Architecture (បែងចែកជាបំណែកតូចៗ)៖ បំបែកផ្ទៃគេហទំព័រទាំងមូលជាបំណែកតូចៗដាច់ដោយឡែកពីគ្នា (Component) ដែលបង្កើតតែម្តង ប៉ុន្តែអាចយកទៅប្រើឡើងវិញបានច្រើនដង។
  • Virtual DOM (បង្កើនល្បឿនគេហទំព័រ)៖ ជាទម្រង់ចម្លងនៃ DOM ក្នុង Memory ដែលជួយកែប្រែតែចំណុចណាដែលមានការផ្លាស់ប្តូរប៉ុណ្ណោះ ដោយមិនបាច់ Reload ទំព័រទាំងមូលឡើងវិញឡើយ។

លក្ខណៈពិសេសស្នូលរបស់ React.js៖

  • Declarative UI៖ យើងគ្រាន់តែកំណត់រូបរាង UI ទៅតាមទិន្នន័យ នោះ React នឹងរៀបចំបង្ហាញលើអេក្រង់ឱ្យដោយស្វ័យប្រវត្តិ (ដោយមិនបាច់ប្រើ document.getElementById() ទៅចាប់ DOM កែប្រែដោយដៃដូច JavaScript ឡើយ)។
  • Unidirectional Data Flow៖ ទិន្នន័យត្រូវបានបញ្ជូនក្នុងទិសដៅតែមួយ គឺពីលើចុះក្រោម (Parent ➔ Child) ធ្វើឱ្យងាយស្រួលគ្រប់គ្រង និងស្វែងរកកំហុស។

3. ប្រើពេលណា (When to Use):

ប្រើសម្រាប់បង្កើតគេហទំព័រដែលមានទិន្នន័យផ្លាស់ប្តូរញឹកញាប់ ដូចជា Admin Dashboard, Social Media, E-commerce និង Web Apps ទំនើបៗ។

4. Syntax (ទម្រង់កូដ):

function App() {
  return (
    <div style={{ padding: '12px', background: '#E0F2FE', borderRadius: '6px' }}>
      <h1 style={{ color: '#0284C7', margin: '0 0 4px' }}>សួស្តី React.js!</h1>
      <p style={{ margin: 0, color: '#0F172A' }}>ស្វាគមន៍មកកាន់ការសិក្សា React.js ពីមូលដ្ឋាន!</p>
    </div>
  );
}

export default App;

http://localhost:5173

ស្វាគមន៍មកកាន់ការសិក្សា React.js ពីមូលដ្ឋាន!

6. Summary (សង្ខេបមេរៀន)៖ React គឺជា UI Library ដំណើរការតាមរយៈ Component និង Virtual DOM ជួយឱ្យ Web Application ដំណើរការលឿន មិនបាច់ Reload ទំព័រឡើយ។

React.js 02. Vite Setup & Project Structure

02. React Setup (Vite) & Project Structure

1. Definition (និយមន័យ):

Vite គឺជា Build Tool ជំនាន់ថ្មីដែលប្រើសម្រាប់បង្កើត និងដំណើរការគម្រោង React.js យ៉ាងលឿនបំផុត ដោយគាំទ្រ Hot Module Replacement (HMR) មានន័យថា កែកូដភ្លាមឃើញលទ្ធផលភ្លាម។

2. មុខងារ និងពាក្យបញ្ជាសំខាន់ៗ:

  • npm create vite@latest my-app -- --template react ៖ បង្កើតគម្រោង React ថ្មីតាមរយៈ Vite។
  • npm install ៖ ទាញយក និងដំឡើងបណ្ណាល័យចាំបាច់ទាំងអស់ចូលក្នុងថត node_modules/។
  • npm run dev ៖ ប្រើសម្រាប់ Run Project។

តួនាទី File និង Folder ទាំងអស់ដែលកើតឡើងដោយស្វ័យប្រវត្តិ (Default Project Structure)៖

  • node_modules/ (Packages Folder)៖ ថតផ្ទុកកូដ Libraries ទាំងអស់របស់ React និង Vite ដែលបានទាញយកមកដំឡើង។
  • public/ (Static Folder)៖ ថតផ្ទុកឯកសារ Static ដូចជា Favicon (vite.svg) ឬរូបភាពដែលហៅប្រើដោយផ្ទាល់។
  • src/ (Source Code Folder)៖ ថតស្នូលសម្រាប់សរសេរកូដ React ទាំងអស់ ដែលខាងក្នុងមាន៖
    • assets/ ៖ ថតផ្ទុករូបភាព ឬ Icons (react.svg) សម្រាប់ Import ចូលក្នុង Components។
    • main.jsx (Entry Point)៖ ឯកសារចាប់ផ្តើមដែលនាំយក App.jsx ទៅបញ្ចូលក្នុង #root នៃ index.html។
    • App.jsx (Root Component)៖ Component មេសម្រាប់សរសេរ និងប្រមូលផ្តុំ UI ទាំងអស់នៃកម្មវិធី។
    • App.css & index.css (Stylesheets)៖ ឯកសារ CSS សម្រាប់តុបតែង App.jsx និងកំណត់ Style រួមទូទាំងគេហទំព័រ។
  • index.html (Main HTML)៖ ឯកសារ HTML តែមួយគត់របស់ SPA ដែលផ្ទុក <div id="root"> សម្រាប់បង្ហាញ React UI។
  • package.json (Project Config)៖ កត់ត្រាឈ្មោះគម្រោង, Scripts (dev, build) និងបញ្ជី Libraries ដែល បានដំឡើងចូល Project។
  • package-lock.json (Dependency Lock)៖ ចាក់សោលេខ Version ជាក់លាក់នៃ Libraries ទាំងអស់ ដើម្បីឱ្យការដំឡើងលើម៉ាស៊ីនផ្សេងដំណើរការដូចគ្នា ១០០%។
  • vite.config.js (Vite Configuration)៖ ឯកសារកំណត់ការដំណើរការ និង Plugins របស់ Vite។
  • eslint.config.js (Code Linter)៖ ឯកសារកំណត់ច្បាប់ត្រួតពិនិត្យ និងជួយរកកំហុស Syntax ក្នុងកូដ JavaScript / React។
  • .gitignore (Git Ignore)៖ កំណត់ឈ្មោះថត ឬឯកសារ ដូចជា node_modules/ ដែលមិនត្រូវ Upload ទៅកាន់ GitHub។

3. Syntax (ពាក្យបញ្ជាបង្កើត Project ក្នុង Terminal):

npm create vite@latest my-react-app -- --template react
cd my-react-app
npm install
npm run dev
4. Summary (សង្ខេបមេរៀន)៖ ប្រើ Vite ដើម្បីបង្កើតគម្រោង React ហើយត្រូវចងចាំលំហូរការងារ៖ index.html (#root) ➔ src/main.jsx ➔ src/App.jsx។

React.js 03. JSX (JavaScript XML)

03. JSX (JavaScript XML)

1. Definition (និយមន័យ):

JSX (JavaScript XML) គឺជាការសរសេរកូដដែលមានទម្រង់ស្រដៀងនឹង HTML នៅក្នុង JavaScript ដើម្បីបង្កើត UI និងរៀបចំ Layout។

2. មុខងារ និងច្បាប់សំខាន់ៗក្នុង JSX:

  • ភាពខុសគ្នារវាង JS និង JSX ក្នុង Component៖ ផ្នែកខាងលើ return (បង្កើតអថេរ, Function, គណនា) គឺជាកូដ JavaScript (JS) ធម្មតា ចំណែកកូដដែលនៅខាងក្នុង return (...) គឺជាកូដ JSX។
  • <>...</> (React Fragment)៖ ប្រើសម្រាប់រុំព័ទ្ធធាតុ JSX ច្រើនចូលគ្នាជា Single Root ដោយមិនបង្កើត <div> លើសក្នុង DOM។
  • { expression } (JavaScript Expressions)៖ ដាក់អថេរ ការគណនាលេខ ឬ Ternary Operator នៅក្នុងសញ្ញាខ្នងក្រពើ { }។

ច្បាប់របស់ JSX៖

  • Single Root Element (ត្រូវមាន Parent ក្តោប)៖ មិនអាច return ធាតុ (Elements) ច្រើននៅទន្ទឹមគ្នាបានទេ គឺត្រូវតែមាន Tag មេមួយនៅខាងក្រៅក្តោបជានិច្ច ដូចជា <div>...</div> ឬ Fragment <>...</>។
  • Close All Tags៖ គ្រប់ស្លាកទាំងអស់ត្រូវបិទជានិច្ច រួមទាំងស្លាកទោលដូចជា <img />, <input />, <br />។
  • camelCase Attributes៖ ប្រើ className ជំនួស class និងប្រើ htmlFor ជំនួស for។

3. Syntax (ទម្រង់កូដបែងចែក JS និង JSX):

function CourseInfo() {
  // 1. ផ្នែក JavaScript (JS) ធម្មតា (មុន return)
  const title = "React.js ពីមូលដ្ឋានដល់ការអនុវត្ត";
  const fee = 45;

  // 2. ផ្នែក JSX ចាប់ផ្តើមពីក្នុង return (...)
  return (
    <>
      <h3 style={{ color: '#0284C7', margin: '0 0 4px' }}>វគ្គ៖ {title}</h3>
      <p style={{ margin: '0 0 8px' }}>តម្លៃ៖ ${fee} (ចុះសល់ត្រឹម ${fee - 10})</p>
      <input type="text" placeholder="បញ្ចូលឈ្មោះសិស្ស..." />
    </>
  );
}

export default CourseInfo;

4. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173

វគ្គ៖ React.js ពីមូលដ្ឋានដល់ការអនុវត្ត

តម្លៃ៖ $45 (ចុះសល់ត្រឹម $35)

5. Summary (សង្ខេបមេរៀន)៖ ខាងលើ return ជាកូដ JS ធម្មតា រីឯក្នុង return (...) ជា JSX ហើយប្រសិនបើចង់ return ចាប់ពី ២ ធាតុឡើងទៅ ត្រូវមាន Parent ក្តោបដាច់ខាត (<>...</>) និងប្រើ { } បង្ហាញតម្លៃអថេរ ឬ Expression (កន្សោមគណនា)។

React.js 04. Destructuring (ES6+)

04. Array & Object Destructuring (ES6+)

1. Definition (និយមន័យ):

Destructuring គឺជា Syntax ក្នុង ES6+ សម្រាប់ទាញយកតម្លៃចេញពី Array ឬ Object មកផ្ទុកក្នុង Variables ដាច់ដោយឡែកយ៉ាងរហ័ស និងមានរបៀប។

2. មុខងារ និងទម្រង់សំខាន់ៗ:

  • const [a, b] = array (Array Destructuring)៖ ទាញយកធាតុតាមលំដាប់ Index (តែងប្រើជាមួយ useState)។
  • const { key1, key2 } = obj (Object Destructuring)៖ ទាញយកតម្លៃតាមឈ្មោះ Key ផ្ទាល់ដោយមិនគិតលំដាប់ (តែងប្រើជាមួយ Props)។

ការអនុវត្តជាក់ស្តែងក្នុង React.js៖

  • React Hooks៖ const [count, setCount] = useState(0) បំបែកតម្លៃ State និង Setter Function។
  • Component Props៖ function Card({ title, price }) ជួយកុំឱ្យសរសេរ props.title ផ្ទួនៗ។

3. Syntax (ទម្រង់កូដ):

// ១. Array Destructuring តាមលំដាប់លំដោយ Index
const tools = ["React", "Vite"];
const [primaryTool, buildTool] = tools;

// ២. Object Destructuring តាមឈ្មោះ Property Key
const teacher = { fullName: "លាត ប្រុស", skill: "React.js" };

function Profile() {
  const { fullName, skill } = teacher;
  return (
    <p>លោកគ្រូ <strong>{fullName}</strong> បង្រៀន {skill} ជាមួយ {primaryTool} & {buildTool}</p>
  );
}

export default Profile;

4. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173

លោកគ្រូ លាត ប្រុស បង្រៀន React.js ជាមួយ React & Vite

5. Summary (សង្ខេបមេរៀន)៖ Destructuring ធ្វើឱ្យកូដខ្លីស្អាត ដោយ Array Destructuring ប្រើសម្រាប់ Hooks (useState) និង Object Destructuring ប្រើសម្រាប់ Props។

React.js 05. React Components (Export & Import)

05. React Components (Export & Import)

1. Definition (និយមន័យ):

Component គឺជា ផ្នែកតូចៗនៃ Website ដែលយើងបង្កើតតែម្តង ប៉ុន្តែអាចយកទៅប្រើឡើងវិញបានច្រើនដង (Reusable) ដែលត្រូវបានសរសេរជាទម្រង់ Function របស់ JavaScript ដែលត្រឡប់ (Return) ជាកូដ JSX ដើម្បីបង្កើតជាផ្នែកណាមួយនៃផ្ទាំង UI (Navbar, Button, Card)។

2. មុខងារ និងច្បាប់សំខាន់ៗ:

  • PascalCase Naming៖ ឈ្មោះ Component ត្រូវតែផ្តើមដោយ អក្សរធំ (Capital Letter) ជានិច្ច ដូចជា Navbar, ProductCard ដើម្បីឱ្យ React ស្គាល់ថាជា Component មិនមែន HTML Tag។
  • Component Composition៖ ការយក Component តូចៗទៅហៅប្រើនៅខាងក្នុង Component ធំមួយទៀត ដូចជា <Header /> នៅក្នុង App.jsx។

ការ Export មាន ២ ប្រភេទ៖

  • Default Export៖ ប្រើសម្រាប់បញ្ជូន Component គោលតែមួយចេញពីឯកសារ ហើយពេល import អាចដាក់ឈ្មោះអ្វីក៏បានដោយមិនបាច់ប្រើ { }។
  • Named Export៖ ប្រើសម្រាប់បញ្ជូន Component ឬ Function ច្រើនចេញពីឯកសារតែមួយ ហើយពេល import ត្រូវដាក់ក្នុង { Name } ឱ្យដូចឈ្មោះដើម។

3. Syntax (ការបង្កើត Export និង Import Component):

// ១. ឯកសារ Header.jsx (បង្កើត និង Export Component)
export function Badge() {
  return <span>✨ វគ្គសិក្សាថ្មី</span>;
}

function Header() {
  return <h3 style={{ color: '#0284C7', margin: '0 0 4px' }}>Bros Like Teaching Academy</h3>;
}
export default Header;

// ២. ឯកសារ App.jsx (Import មកប្រើប្រាស់)
import Header, { Badge } from './Header.jsx';

React.js 06. Props

06. Props (Component Communication)

1. Definition (និយមន័យ):

Props (Properties) គឺជាការបញ្ជូនទិន្នន័យពី Component មេ (Parent) ទៅកាន់ Component កូន (Child)។

2. មុខងារ និងច្បាប់សំខាន់ៗនៃ Props:

  • Pass via Attributes៖ បញ្ជូនទិន្នន័យពី Parent តាមឈ្មោះ Property ដូចជា name="សុខា" ឬ isOnline={true}។
  • Receive via Destructuring៖ ទទួលទិន្នន័យក្នុង Child Component តាម function Child({ name, role })។

គោលការណ៍ស្នូលរបស់ Props៖

  • Read-Only (Immutability)៖ ធាតុកូនមានសិទ្ធិត្រឹមតែអានយក Props មកបង្ហាញប៉ុណ្ណោះ ហាមកែប្រែតម្លៃ Props ដោយផ្ទាល់។
  • Data Types៖ អាចបញ្ជូន String, Number, Boolean, Array, Object ហើយសូម្បីតែ Function ក៏អាចបញ្ជូនទៅបាន។

3. ប្រើពេលណា (When to Use):

ប្រើនៅពេលដែលយើងចង់ប្រើប្រាស់ Component ដដែលឡើងវិញ (Reusable) ប៉ុន្តែឱ្យវាបង្ហាញទិន្នន័យ ឬព័ត៌មានខុសៗគ្នា។

4. Syntax (ទម្រង់កូដ):

// Component កូន (ទទួល Props តាមរយៈ Destructuring)
function UserBadge({ name, role, isOnline }) {
  return (
    <div>
      <strong>{name}</strong> - {role} | ស្ថានភាព៖ {isOnline ? "🟢 Online" : "⚪ Offline"}
    </div>
  );
}

// Component មេ (បញ្ជូន Props)
function App() {
  return (
    <div>
      <UserBadge name="លាត ប្រុស" role="Instructor" isOnline={true} />
      <UserBadge name="សុខា" role="Student" isOnline={false} />
    </div>
  );
}

http://localhost:5173

6. Summary (សង្ខេបមេរៀន)៖ Props គឺជាការបញ្ជូនទិន្នន័យពី Component មេ ទៅ Component កូន ដើម្បីឱ្យ Component កូនអាចបង្ហាញទិន្នន័យខុសៗគ្នាបាន។

React.js 07. State & useState Hook

07. State and useState Hook

1. Definition (និយមន័យ):

React Hooks គឺជា Functions ពិសេសដែលភ្ជាប់មកស្រាប់ក្នុង React សម្រាប់អនុញ្ញាតឱ្យ Functional Component អាចគ្រប់គ្រងទិន្នន័យ (State) ដែលធ្វើឱ្យ Component អាច Re-render បាន ដោយមិនចាំបាច់សរសេរជា Class Component ឡើយ។ Hooks សំខាន់ៗដែលគេនិយមប្រើរួមមាន useState(), useEffect(), useRef() និង useReducer()។

2. មុខងារ និងធាតុផ្សំសំខាន់ៗនៃ useState:

  • import { useState } from 'react' (នាំចូល Hook)៖ ទាញយក useState ពីបណ្ណាល័យ React មកប្រើប្រាស់។
  • const [count, setCount] = useState(0) (ប្រកាស State)៖ បង្កើតអថេរផ្ទុកទិន្នន័យ និង Function សម្រាប់កែប្រែតម្លៃដោយកំណត់តម្លៃដើម 0។

សមាសធាតុទាំង ៣ របស់ useState៖

  • State Variable (count)៖ អថេរសម្រាប់ផ្ទុកតម្លៃបច្ចុប្បន្ន និងយកទៅបង្ហាញលើអេក្រង់ (UI)។
  • Setter Function (setCount)៖ Function សម្រាប់ផ្លាស់ប្តូរតម្លៃ State និងបញ្ជាឱ្យ Component ធ្វើការ Re-render (ហាមកែ count = 1 ដោយផ្ទាល់)។
  • Initial Value (0)៖ តម្លៃចាប់ផ្តើមដំបូងបង្អស់នៅពេល Component បើកដំណើរការ។

3. ប្រើពេលណា (When to Use):

ប្រើរាល់ពេលដែលចង់យកតម្លៃទៅបង្ហាញលើផ្ទាំង UI (អាចគិតថាវាដូចជា Variable ពិសេសបាន)។

4. Syntax (ទម្រង់កូដ):

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h3>ចំនួនចុច៖ {count}</h3>
      <button onClick={() => setCount(count + 1)}>បន្ថែម +1</button>
      <button onClick={() => setCount(0)}>កំណត់ឡើងវិញ</button>
    </div>
  );
}
5. Summary (សង្ខេបមេរៀន)៖
- React Hooks៖ គឺជា Functions ពិសេសដែលអនុញ្ញាតឱ្យ Functional Component អាចគ្រប់គ្រង State និងមុខងារផ្សេងៗរបស់ React បានដោយផ្ទាល់។
- useState៖ ប្រើសម្រាប់ផ្ទុកទិន្នន័យ (Variable ពិសេស) និងធ្វើឱ្យ Component អាច Re-render ផ្ទាំង UI ឡើងវិញដោយស្វ័យប្រវត្តិ នៅពេលកែប្រែតម្លៃតាមរយៈ Setter Function។

React.js 08. Event Handling

08. Event Handling (Synthetic Events)

1. Definition (និយមន័យ):

Event Handling គឺជាការឆ្លើយតបទៅនឹងសកម្មភាពរបស់អ្នកប្រើប្រាស់ (ដូចជាការចុច Click ឬការវាយអត្ថបទ) នៅលើផ្ទាំង UI របស់ React។

2. មុខងារ និងច្បាប់សំខាន់ៗ:

  • onClick={handleClick} (Click Event)៖ ចាប់ព្រឹត្តិការណ៍ពេលចុចប៊ូតុង ដោយបញ្ជូនជា Function Reference។
  • onChange={(e) => ...} (Change Event)៖ ចាប់ព្រឹត្តិការណ៍ពេលតម្លៃក្នុង Input មានការផ្លាស់ប្តូរ។

ការបំបែកសមាសធាតុនៃ Event Object (e.target.value)៖

  • e (Event Object)៖ កញ្ចប់ព័ត៌មាននៃព្រឹត្តិការណ៍ដែល React បង្កើត និងបញ្ជូនមកឱ្យ Function ដោយស្វ័យប្រវត្តិពេលមានព្រឹត្តិការណ៍កើតឡើង។
  • .target (Target Element)៖ សំដៅទៅលើធាតុ HTML ជាក់លាក់ដែលអ្នកប្រើប្រាស់កំពុងធ្វើសកម្មភាពលើវាផ្ទាល់។
  • .value (Input Value)៖ ប្រើសម្រាប់ចាប់តម្លៃដែលអ្នកប្រើប្រាស់បានវាយបញ្ចូលនៅក្នុង .target នោះ។

ចំណុចសម្គាល់សំខាន់ៗក្នុង React Events៖

  • camelCase Convention៖ សរសេរ onClick, onChange, onSubmit ជំនួសអក្សរតូចទាំងអស់របស់ HTML។
  • e.preventDefault()៖ ប្រើនៅក្នុង onSubmit ដើម្បីការពារកុំឱ្យ Form ធ្វើការ Refresh ទំព័រទាំងមូល។
  • ហាមដាក់វង់ក្រចក () នៅចុងឈ្មោះ Function៖ ត្រូវសរសេរ onClick={handleClick} ជំនួសឱ្យ handleClick() ព្រោះការដាក់ () នឹងធ្វើឱ្យ Function ដំណើរការភ្លាមៗដោយស្វ័យប្រវត្តិពេល Component Render ដោយមិនរង់ចាំអ្នកប្រើចុច (និងអាចបង្កជា Infinite Loop ប្រសិនបើមានការកែប្រែ State)។

3. Syntax (ទម្រង់កូដ):

import { useState } from 'react';

function InputLogger() {
  const [text, setText] = useState("");

  // របៀបទី 1៖ បង្កើត Function ផ្សេង រួចហៅឈ្មោះមកប្រើ
  const handleChange = (e) => setText(e.target.value);

  return (
    <div>
      <input type="text" placeholder="វាយអត្ថបទទីនេះ..." onChange={handleChange} />

      {/* របៀបទី 2៖ សរសេរ Arrow Function នៅលើ Event ផ្ទាល់ */}
      <button onClick={() => setText("")} style={{ marginLeft: '6px' }}>សម្អាត</button>

      <p>អក្សរដែលអ្នកវាយ៖ <strong style={{ color: '#0284C7' }}>{text}</strong></p>
    </div>
  );
}
4. Summary (សង្ខេបមេរៀន)៖ Events ក្នុង React សរសេរជា camelCase ហើយបញ្ជូនជា Function Reference ឬ Arrow Function។ ប្រើ e.target.value ដើម្បីចាប់តម្លៃពី Input និង e.preventDefault() ដើម្បីការពារការ Refresh Form។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 11
React.js 09. Conditional Rendering

09. Conditional Rendering

1. Definition (និយមន័យ):

Conditional Rendering គឺជាការសម្រេចចិត្តបង្ហាញ ឬលាក់ធាតុ UI ណាមួយដោយផ្អែកលើលក្ខខណ្ឌពិត (true) ឬមិនពិត (false) នៃ State ឬ Props។

2. មុខងារ និង Operators សំខាន់ៗ:

  • { condition ? <A /> : <B /> } (Ternary Operator)៖ បង្ហាញ UI ពីរផ្ទុយគ្នាអាស្រ័យលើលក្ខខណ្ឌពិត ឬមិនពិត។
  • { condition && <A /> } (Logical AND)៖ បង្ហាញធាតុ A លុះត្រាតែលក្ខខណ្ឌពិត (បើមិនពិត មិនបង្ហាញអ្វីទាំងអស់)។
  • { data ?? "តម្លៃជំនួស" } (Nullish Coalescing)៖ បង្ហាញតម្លៃជំនួស ប្រសិនបើ data មានតម្លៃ null ឬ undefined។

3. Syntax (ទម្រង់កូដ):

import { useState } from 'react';

function AuthStatus({ username }) {
  const [isLoggedIn, setIsLoggedIn] = useState(true);

  return (
    <div>
      {/* 1. ប្រើ Nullish Coalescing (??) បង្ហាញតម្លៃជំនួសពេលទទេ */}
      <p>សួស្តី៖ {username ?? "ភ្ញៀវ (Guest)"}</p>

      {/* 2. ប្រើ Ternary Operator (? :) ជ្រើសរើសប៊ូតុង */}
      {isLoggedIn ? (
        <button onClick={() => setIsLoggedIn(false)}>ចាកចេញ (Logout)</button>
      ) : (
        <button onClick={() => setIsLoggedIn(true)}>ចូលគណនី (Login)</button>
      )}

      {/* 3. ប្រើ Logical AND (&&) បង្ហាញសារពេល Login រួច */}
      {isLoggedIn && <p>✓ អ្នកកំពុងស្ថិតក្នុងគណនី</p>}
    </div>
  );
}
4. Summary (សង្ខេបមេរៀន)៖ ប្រើ ? : សម្រាប់ជម្រើស UI ២ ផ្ទុយគ្នា, ប្រើ && សម្រាប់បង្ហាញពេលលក្ខខណ្ឌពិត និងប្រើ ?? សម្រាប់ដាក់តម្លៃជំនួសពេលទិន្នន័យទទេ (null/undefined)។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 12

10. Lists Rendering

1. Definition (និយមន័យ):

Lists Rendering គឺជាការទាញយកទិន្នន័យច្រើនៗពីក្នុង Array មកបង្ហាញជាបញ្ជីនៅលើផ្ទាំង UI ដោយប្រើ .map()។

2. មុខងារ និងធាតុផ្សំសំខាន់ៗ:

  • array.map((item) => <Li />) (Mapping)៖ រត់កាត់ទិន្នន័យម្តងមួយៗក្នុង Array រួចបំប្លែងទៅជាស្លាក JSX ដោយស្វ័យប្រវត្តិ។
  • key={item.id} (Unique Key Prop)៖ កំណត់លេខសម្គាល់មិនស្ទួនលើធាតុមេនៃ map() ជានិច្ច។

ហេតុអ្វីបានជា key មានសារៈសំខាន់បំផុត?

  • Virtual DOM Tracking៖ ជួយឱ្យ React ដឹងច្បាស់ថាធាតុណាត្រូវបានបន្ថែម កែប្រែ ឬលុបចេញ ដោយមិនបាច់គូសបញ្ជីទាំងមូលឡើងវិញ (ចៀសវាងប្រើ Index ជា Key ពេលបញ្ជីអាចលុប ឬតម្រៀបបាន)។

3. Syntax (ទម្រង់កូដ):

const courses = [

5. Summary (សង្ខេបមេរៀន)៖ ការបង្ហាញទិន្នន័យបញ្ជីត្រូវប្រើ Array.map() និងតម្រូវឱ្យមាន key ពិសេសមិនស្ទួនគ្នាលើធាតុមេជានិច្ច ដើម្បីកុំឱ្យ React ច្រឡំគ្នាពេលមានការកែប្រែ ឬលុបទិន្នន័យ។

React.js 11. Forms Handling

11. Forms Handling (Controlled Components)

1. Definition (និយមន័យ):

Forms Handling គឺជាការគ្រប់គ្រង Form នៅក្នុង React ដោយភ្ជាប់តម្លៃរបស់ Input ទៅនឹង State ទាំងស្រុង។

2. មុខងារ និងវិធីសាស្ត្រសំខាន់ៗ:

  • value={state} & onChange (Two-Way Binding)៖ ភ្ជាប់តម្លៃ Input ទៅ State និងធ្វើបច្ចុប្បន្នភាពរាល់ពេលវាយអក្សរ។
  • onSubmit={handleSubmit} (Form Submission)៖ ចាប់ព្រឹត្តិការណ៍ពេលចុចប៊ូតុង Submit ឬចុច Enter។

មុខងារចាំបាច់ពេល Submit Form៖

  • e.preventDefault()៖ ទប់ស្កាត់កុំឱ្យ Browser ធ្វើការ Refresh ទំព័រឡើងវិញដែលធ្វើឱ្យបាត់បង់ State ទាំងអស់។
  • Reset Input (setEmail(""))៖ កំណត់ State ឱ្យទទេវិញដើម្បីសម្អាតប្រអប់ Input ក្រោយបញ្ជូនទិន្នន័យរួច។

3. Syntax (ទម្រង់កូដ):

import { useState } from 'react';

function LoginForm() {
  const [email, setEmail] = useState("");

  const handleSubmit = (e) => {
    e.preventDefault(); // ការពារកុំឱ្យ Refresh ទំព័រ
    alert(`បានបញ្ជូនអ៊ីមែល៖ ${email}`);
    setEmail(""); // សម្អាតប្រអប់ក្រោយ Submit
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="email" value={email} onChange={(e) => setEmail(e.target.value)} placeholder="you@email.com" />
      <button type="submit">បញ្ជូន</button>
    </form>
  );
}

4. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173
5. Summary (សង្ខេបមេរៀន)៖ ការគ្រប់គ្រង Form ត្រូវភ្ជាប់ value និង onChange ទៅ State ព្រមទាំងប្រើ e.preventDefault() ដើម្បីទប់ស្កាត់ការ Refresh ទំព័រឡើងវិញ។

React.js 12. LocalStorage Persistence

12. LocalStorage & Data Persistence

1. Definition (និយមន័យ):

LocalStorage គឺជា Web Storage API របស់ Browser សម្រាប់រក្សាទុកទិន្នន័យជាអចិន្ត្រៃយ៍លើម៉ាស៊ីនអ្នកប្រើប្រាស់ ទោះបីជាបិទ ឬ Refresh Browser ក៏មិនបាត់បង់ទិន្នន័យដែរ។

2. មុខងារ និង Methods សំខាន់ៗ:

  • localStorage.setItem('key', val) (Save)៖ រក្សាទុកទិន្នន័យចូលក្នុង Storage របស់ Browser។
  • localStorage.getItem('key') (Read)៖ ទាញយកទិន្នន័យចេញពី Storage មកប្រើប្រាស់។
  • localStorage.removeItem('key') (Delete)៖ លុបទិន្នន័យចេញពី Storage តាមឈ្មោះ Key។
  • localStorage.clear() (Clear All)៖ លុបទិន្នន័យទាំងអស់ចេញពី Storage របស់ Browser។

ការបម្លែងទិន្នន័យ Array / Object ទៅជាមួយ JSON៖

  • JSON.stringify(data) ៖ LocalStorage ស្គាល់តែ String ដូច្នេះត្រូវបម្លែង Array/Object ទៅជា JSON String មុនរក្សាទុក។
  • JSON.parse(str) ៖ បម្លែង JSON String ត្រឡប់មកជា Array/Object វិញពេលទាញយកមកដាក់ក្នុង React State។

3. ប្រើពេលណា (When to Use):

ប្រើសម្រាប់រក្សាទុកទិន្នន័យក្នុងកន្ត្រកទំនិញ (Shopping Cart)​ និងការកំណត់ Theme (Dark/Light Mode)។

4. Syntax (ទម្រង់កូដ):

import { useState, useEffect } from 'react';

function NameSaver() {
  const [name, setName] = useState(() => localStorage.getItem("app_user") || "");

  useEffect(() => {
    localStorage.setItem("app_user", name);
  }, [name]);

  return <input value={name} onChange={(e) => setName(e.target.value)} />;
}
5. Summary (សង្ខេបមេរៀន)៖ LocalStorage រក្សាទុកទិន្នន័យអចិន្ត្រៃយ៍នៅលើ Browser ដោយប្រើ setItem() សម្រាប់រក្សាទុក និង getItem() សម្រាប់ទាញយកទិន្នន័យមកប្រើប្រាស់វិញ។

React.js 13. React Hooks

13. React Hooks (useEffect & useRef)

1. Definition (និយមន័យ):

React Hooks គឺជា Function ពិសេសរបស់ React។ ដោយ useEffect ប្រើសម្រាប់បញ្ជាឱ្យកូដដំណើរការស្វ័យប្រវត្តិក្រោយពេល Render រួច។ ចំណែក useRef ប្រើសម្រាប់ចាប់យកធាតុ HTML មកបញ្ជាដោយផ្ទាល់។

2. មុខងារ និងភាពខុសគ្នាសំខាន់ៗ:

  • useEffect (Side Effects)៖ ដំណើរការកូដក្រោយពេល Render រួច (ដូចជាការទាញ API, Timer ឬរក្សាទុក LocalStorage)៖
    • useEffect(() => {}) (គ្មាន Array)៖ ដំណើរការរាល់ពេល Component ធ្វើការ Render ឡើងវិញ។
    • useEffect(() => {}, []) (Empty Array)៖ ដំណើរការតែ ១ ដងគត់ពេលបើកទំព័រដំបូង (Mount)។
    • useEffect(() => {}, [data]) (Dependencies)៖ ដំណើរការរាល់ពេលតម្លៃ data មានការផ្លាស់ប្តូរ។
  • const myRef = useRef(null) (DOM Reference)៖ ភ្ជាប់ទៅធាតុ HTML ផ្ទាល់តាម ref={myRef} ដើម្បីបញ្ជា .focus() ដោយមិនបង្កឱ្យ Re-render។

3. ប្រើពេលណា (When to Use):

ប្រើ useEffect ពេលទាញទិន្នន័យពី API និងប្រើ useRef ពេលចង់ឱ្យ Cursor លោតចូលប្រអប់ Input ស្វ័យប្រវត្តិ ឬគ្រប់គ្រង Video Player។

4. Syntax (ទម្រង់កូដ):

import { useEffect, useRef } from 'react';

function AutoFocusInput() {
  const inputRef = useRef(null);

  useEffect(() => {
    inputRef.current.focus(); // ឱ្យ Cursor លោតចូល Input ភ្លាម
  }, []);

  return <input ref={inputRef} placeholder="វាយទីនេះភ្លាមៗ..." />;
}

5. Output (លទ្ធផលនៅលើ Browser):

http://localhost:5173
✨ Cursor លោតចូលប្រអប់ស្វ័យប្រវត្តិតាមរយៈ useRef + useEffect
6. Summary (សង្ខេបមេរៀន)៖ useEffect ដោះស្រាយ Side Effects តាមរយៈ Dependency Array រីឯ useRef ចាប់យក DOM ផ្ទាល់ដោយមិនធ្វើឱ្យ Re-render។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 16

14. React Router (Client-Side Navigation)

1. Definition (និយមន័យ):

React Router (react-router) គឺជា Library របស់ React ដែលប្រើសម្រាប់គ្រប់គ្រងការផ្លាស់ប្តូរទំព័រនៅលើ Browser ដោយមិនបាច់ Reload ទំព័រឡើងវិញឡើយ។

  • Components ស្នូល៖
    • <BrowserRouter>៖ Component មេធំបំផុតដែលរុំព័ទ្ធកម្មវិធីដើម្បីបើកដំណើរការ URL Routing។
    • <Routes>៖ ផ្ទុក និងគ្រប់គ្រងបញ្ជីផ្លូវ (Route) ទាំងអស់របស់វេបសាយ។
    • <Route path="..." element={...} />៖ កំណត់ផ្លូវ URL និងបង្ហាញ Component តាម Path នីមួយៗ។
    • <Link to="...">៖ ប្រើជំនួសស្លាក <a> ដើម្បីចុចប្តូរទំព័រដោយគ្មានការ Reload។
    • <NavLink to="...">៖ ដូច Link ដែរ តែអាចដឹងថា Menu មួយណាកំពុង Active។
    • <Outlet />៖ បង្ហាញទំព័រកូន (Nested Routes) នៅខាងក្នុង Layout រួម។
    • <Navigate to="..." />៖ រុញអ្នកប្រើប្រាស់ទៅទំព័រផ្សេងដោយស្វ័យប្រវត្តិ (Redirect)។
  • Hooks សំខាន់ៗ៖
    • useNavigate()៖ បញ្ជាឱ្យប្តូរទំព័រតាមរយៈកូដ JavaScript (ឧ. ក្រោយពេល Login ជោគជ័យ)។
    • useParams()៖ ចាប់យកតម្លៃ Dynamic Parameter ពីលើ URL (ឧ. /products/:id)។
    • useSearchParams()៖ អាន និងកែប្រែ Query String នៅខាងក្រោយ URL (ឧ. ?search=react)។
    • useLocation()៖ ទាញយកព័ត៌មានលម្អិតនៃទីតាំង URL បច្ចុប្បន្នដែលកំពុងស្ថិតនៅ។

3. Syntax (ទម្រង់កូដ):

import { BrowserRouter, Routes, Route } from 'react-router';

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<h3>ស្វាគមន៍មកកាន់ទំព័រដើម</h3>} />
        <Route path="/about" element={<h3>ព័ត៌មានអំពីយើង</h3>} />
      </Routes>
    </BrowserRouter>
  );
}
4. Summary (សង្ខេបមេរៀន)៖ React Router ជួយឱ្យគេហទំព័រប្តូរទំព័របានរហ័សដោយមិនបាច់ Reload តាមរយៈការប្រើ <Routes> កំណត់ផ្លូវ និង <Link> ជំនួសស្លាក <a>។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 17
React.js 15. API Integration

15. API Integration (Async/Await & Try-Catch-Finally)

1. Definition (និយមន័យ):

API Integration គឺជាការតភ្ជាប់កម្មវិធី React ទៅកាន់ Server ដើម្បីទាញ ឬបញ្ជូនទិន្នន័យ (JSON) ដោយប្រើ fetch() ជាមួយ async/await និង try-catch-finally។

2. មុខងារ និងផ្នែកសំខាន់ៗ:

  • await fetch(url)៖ ផ្ញើសំណើទៅទាញទិន្នន័យពី API Endpoint តាមរយៈ URL។
  • await res.json()៖ បម្លែងទិន្នន័យ Response ដែលទទួលបានទៅជា JavaScript Object / Array។
  • useEffect(() => { fetchData(); }, [])៖ ហៅអនុគមន៍ទាញទិន្នន័យពេលបើកទំព័រដំបូង។
  • តួនាទីនៃប្លុក try-catch-finally៖
    • try { ... }៖ ដាក់កូដ fetch() និងអាចប្រើ throw new Error() ដើម្បីបោះ Error ចេញដោយខ្លួនឯង។
    • catch (err) { ... }៖ ចាប់យក err (Error Object ដែលផ្ទុក err.message) ពេលដាច់អ៊ីនធឺណិត ឬ throw បោះមក។
    • finally { ... }៖ ដំណើរការចុងក្រោយជានិច្ច សម្រាប់បិទ Loading (setLoading(false))។

3. Syntax (ទម្រង់កូដ):

import { useState, useEffect } from 'react';

function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchUsers = async () => {
      try {
        const res = await fetch("https://jsonplaceholder.typicode.com/users");
        if (!res.ok) throw new Error("ទាញទិន្នន័យបរាជ័យ!");
        const data = await res.json();
        setUsers(data);
      } catch (err) {
        console.error(err.message);
      } finally {
        setLoading(false);
      }
    };
    fetchUsers();
  }, []);

  if (loading) return <p>កំពុងទាញទិន្នន័យ...</p>;
  return <ul>{users.map(({ id, name }) => <li key={id}>{name}</li>)}</ul>;
}
4. Summary (សង្ខេបមេរៀន)៖ ការប្រើ async/await ជាមួយ try-catch-finally ជួយឱ្យកូដទាញទិន្នន័យងាយអាន និងធានាថា loading ត្រូវបានបិទជានិច្ចក្នុងប្លុក finally។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 18
React.js 16. Architecture

16. React Architecture

1. Definition (និយមន័យ):

React Architecture គឺជាការរៀបចំរចនាសម្ព័ន្ធ Folders និង Files ឱ្យមានស្តង់ដារតាមតួនាទីនីមួយៗ ដើម្បីងាយស្រួលគ្រប់គ្រង។

2. មុខងាររបស់ Folders និង Files សំខាន់ៗ:

  • src/layouts/ (Page Layouts)៖ ផ្ទុកគ្រោងឆ្អឹងទំព័ររួម ដូចជា MainLayout.jsx, AdminLayout.jsx (ប្រើជាមួយ <Outlet />)។
  • src/components/ (Reusable UI)៖ ផ្ទុកបំណែក UI តូចៗប្រើឡើងវិញបាន ដូចជា Navbar.jsx, Button.jsx។
  • src/pages/ (Page Views)៖ ផ្ទុកទំព័រពេញលេញសម្រាប់ភ្ជាប់ជាមួយ Routes ដូចជា Home.jsx, About.jsx។
  • src/auth/ (Authentication)៖ ផ្ទុកកូដគ្រប់គ្រងការ Login និងសិទ្ធិអ្នកប្រើប្រាស់ ដូចជា AuthContext.jsx, ProtectedRoute.jsx។
  • src/services/ (API Calls)៖ ផ្ទុកកូដភ្ជាប់ទៅកាន់ Backend API (api.js) ដើម្បីកុំឱ្យកូដ Fetch លាយឡំក្នុង UI។
  • src/utils/ (Helpers)៖ ផ្ទុកអនុគមន៍ជំនួយទូទៅ ដូចជាការបម្លែងថ្ងៃខែ ឬរូបិយប័ណ្ណ (formatDate.js)។

ឯកសារស្នូល និងការគ្រប់គ្រង Style៖

  • src/assets/៖ ផ្ទុករូបភាព Logo, Icons និង Fonts ដែលត្រូវ Import យកទៅប្រើក្នុង Components។
  • src/style.css ឬ *.module.css៖ កំណត់ Layout និងប្រព័ន្ធពណ៌ស្តង់ដារដាច់ដោយឡែកពីកូដ JavaScript។

3. ប្រើពេលណា (When to Use):

អនុវត្តលើគ្រប់គម្រោង React ជាក់ស្តែងទាំងអស់ដើម្បីឱ្យ Codebase មានរបៀបរៀបរយ និងងាយស្រួលធ្វើការងារជាក្រុម។

4. Syntax (រចនាសម្ព័ន្ធ Folder ស្តង់ដារ):

src/
├── assets/         // រូបភាព, Logo និង Icons
├── auth/           // គ្រប់គ្រង Login និងសិទ្ធិ (ProtectedRoute.jsx)
├── components/     // បំណែក UI ប្រើឡើងវិញបាន (Navbar, Button)
├── layouts/        // គ្រោងឆ្អឹងទំព័ររួម (MainLayout.jsx)
├── pages/          // ទំព័រពេញលេញភ្ជាប់ Routes (Home, About)
├── services/       // អនុគមន៍ទាញទិន្នន័យ API (api.js)
├── utils/          // អនុគមន៍ជំនួយផ្សេងៗ (formatDate.js)
├── App.jsx         // Component មេគ្រប់គ្រង Routes
├── main.jsx        // ចំណុចចាប់ផ្តើមភ្ជាប់ទៅ DOM (#root)
└── style.css       // CSS ស្តង់ដារសម្រាប់តុបតែង UI
5. Summary (សង្ខេបមេរៀន)៖ ការរៀបចំ Folder Architecture ច្បាស់លាស់ជួយឱ្យ Codebase ស្អាត ងាយស្រួលថែទាំ និងកែសម្រួល ព្រមទាំងបង្កើនប្រសិទ្ធភាពការងារជាក្រុម។
